## 🛠️ 技术栈

- **前端**: Vue 3 + Vite + Tiptap
- **桌面**: Electron 29
- **状态管理**: Pinia
- **AI引擎**: Ollama / DeepSeek
- **Python**: PyMuPDF, Pillow, OpenCV

---

## 📋 系统要求

- Windows 10/11 64位
- Node.js >= 18.x
- Python >= 3.9, < 3.13
- 内存: 8GB+ (推荐16GB)
- 硬盘: 10GB+ 可用空间
