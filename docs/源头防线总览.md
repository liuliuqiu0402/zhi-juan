# 源头防线总览

> 定位：本项目不依赖"事后检查/自动修正"，一律从源头（提示词与生成机制本身）闭环解决。
> 本页汇总所有已就位的源头防线，标注各自锁定的文件与测试，便于核对"哪块已根治、哪块靠人工核对"。
> 最后更新：2026-09-10

---

## 一、核心原则

- **课标理念作引导，机制只作保底**：理念留在判断/意图层，机制一律退为"下限/兜底"，绝不成为"上限/预置"。
- **不依赖事后**：删除"模型整卷重写"与"缺漏→自动补齐"类闭环；问题要么在源头杜绝，要么交由人工核对，程序从不自动改内容。
- **提示词不得以"待达成目标"枚举具体呈现形式/组织序列/递进链**：这类列举即诱导，一律删成原则句。

## 二、防线清单

| # | 防线 | 机制要点 | 锁定文件 / 测试 |
|---|------|---------|----------------|
| 1 | **防诱导不变量** | 提示词不枚举呈现形式/组织序列/递进链，删成原则句；豁免仅两类：渲染契约、答题书写规范 | 常量 `CONTENT_FORMAT`/`LENGTH_DISCIPLINE`（promptLibrary.js）；蓝图/风格/考卷蓝本去枚举；**锁于 tests/config/nonInducingPrompt.test.js** |
| 2 | **预算防截断** | 动态预算 + 触顶自动升级（不静默截断）+ 引擎单次上限自动分次续写补齐 + 截断仍不完整则整卷重试；once 槽"宁多勿截"防答案区截断 | useAiGenerator.js 预算解析/续写/重试段（约 4637–4833）；`LENGTH_DISCIPLINE` 促"写到即止不注水" |
| 3 | **覆盖完整优先（全局）** | "逐点覆盖核心知识与篇幅/题量冲突时，逐点呈现为必要内容，不得以篇幅删减、不得以声明代替呈现" | promptLibrary.js「覆盖完整优先」全局层（约 :92） |
| 4 | **只报不改** | 程序永不自动修改课标维度缺失；缺失/警示全量进报告由人工核对 | coverageProbe / coverageReconciler / covScope / domainReconciler / coverageAnchor / coverageContract；quality 报告链 |
| 5 | **覆盖对账口径** | 对账以研读产出覆盖点为基准，判定词为教材原文语言（specificConcepts），避免中文锚 vs 内容语言不一致 | coverageReconciler.js + coverageProbe.js（对账单）
| 6 | **答题/书写规范白名单** | "解→公式→代入→计算→答"、实验要素、论证规范等答题书写形态保留固定（不产生内容诱导） | 各学科蓝本 note + antiCopyGuard 白名单 |
| 7 | **渲染/载体契约** | 田字格/四线/方格/作答位等载体按学科×题型注入，只定书写物理形态、不反噬内容 | carrierCss.js（单一事实源）+ blueprintSchema.js + eduRenderContract.js |
| 8 | **三维度匹配** | 年级×学科×资料类型注入；卷别→学段映射唯一（xiaoshengchu/zhongkao/gaokao）；生成前学段一致性校验 | teachingBlueprints.js + paperScope.js + blueprintProvider.js + blueprintGuard |
| 9 | **资料内多样** | 「尾约束·资料内多样」：同份资料各栏目呈现形式与组织顺序应有所差异，不得全份同类版式照搬 | useAiGenerator.js 委托书尾（与【全文自洽】同址锚定） |
| 10 | **防照搬护栏** | 阈值留安全余量（英文整句≥10词、中文≥8字、3数字）；学科术语白名单；连词成句词库豁免；只报不改 | antiCopyGuard.js + 白名单（COPY_TERM_WHITELIST） |

## 三、已移除的机制（勿再引入）

| 机制 | 移除理由 |
|------|---------|
| 模型整卷重写修订轮 | 实测两轮 100% 空转（让模型重打整卷+答案区），且重写有篡改达标内容风险 |
| "缺漏→必覆盖→复生成定向补齐"闭环 | 属"事后自动补"，改由覆盖对账报告交人工核对 |
| "恰好 N 个情境"预生成池 | 数量型诱导，违审核基准 C；scenario_each 仅保留组织形态语义 |
| 呈现/序列枚举（表格优先、识记→理解→运用等） | 以目标列举具体形态即诱导，已整体删除并锁入测试 |

## 四、人工核对面（机制刻意不自动处理）

- 覆盖对账"未呈现覆盖点"、防照搬命中、内容自洽判断 → 全部由质量报告输出，交人工判定。
- 分数与课标等级的解读 → 由模型按委托自组织，程序不程序化重算/强制。
- 情境与素材 → 由模型按课标自组织，程序不预设内容。
