# 口径中性化 · 判据与清单（2026-09-14 用户定版）

> 起因：委托书里"覆盖"一族强强调（8 处）把"覆盖"读成了"一条目＝一题/一大题"，
> 导致栏目内的大题只能是清单条目（标题不照抄了、分组逻辑仍来自清单）；题型句又用
> "既要有…也要有…缺则补"指定题型存在。用户裁定：**不能有副作用、不能把路走窄、不能诱导**。
> 本文把这次的做法固定成判据 + 清单，以后遇到同类现象直接比着判，不必每次临时扫。

## 一、两条判据（要不要动，只看这两条）

1. **在不在生成链路上**——会被注入给模型、影响成稿的，才值得动；只进展示/日志的不动。
2. **是不是确定性问题**——格式、合规、计算、术语、载体这类"有唯一正确答案"的条款，
   即使措辞很硬（一律/严禁/必须）**一律保留**：它们是"看到的≠发出去的"治理成果，松了会回退。

两条都满足（进链路 **且** 非确定性）才做中性化。

## 二、中性化的三种手法（保语义、只改指向）

| 手法 | 说明 | 例 |
|---|---|---|
| 换词 | 覆盖 → 练到 / 落到；覆盖下限 → 下限；覆盖单位 → 设题单位；覆盖对账 → 逐条对账 | "至少要全部覆盖到" → "都要练到（这是下限）" |
| 去腔调 | 去掉"不得整项遗漏 / 缺漏即补题 / 严禁 / 逐项齐全"等硬指向，保留要求本身 | 篇幅纪律："完整覆盖全部要求…逐项齐全后方可收尾，严禁…" → "把全部要求都落到实处…栏目与题目齐备后再收尾，不以…" |
| 换依据 | 自造指令 → 课标口径的中性转述（不挂学科课标名，全学科通用） | "既要有客观题也要有书写题，缺则补" → "合理安排不同类型作业的比例，增强作业的可选择性" |

## 三、五类现象的扫描结论（本次全量扫过一遍）

| 类别 | 结论 | 处理 |
|---|---|---|
| A 硬数字指标 | 模型可见文本里**基本已清**（仅剩"不超出本学段课标学业质量要求"这类非硬指标）；`layoutSpec` 的"每式 ≥3 行"属载体规范 | 不动 |
| B 逐点动作指令 | 题类那两处本次已清；余下（质量底线"逐条自查"、题号"逐题自查缺号即补"、复习"逐条给要点"、蓝图栏目 note 20 余处"逐点梳理"）属质量机制 / 确定性问题 / 梳理类资料的形态本身 | 不动 |
| C 举例式 | 分两档：**防错反例**保留（数量纪律"如把 2.05千米 写成 205千米"、术语"如 Chinese 末字母 s 发 /z/"、格式示例、公式"如 1/2"）；**方向性举例**已中性化（蓝图命题要求 4 处，见四） | 只改方向性举例 |
| D 绝对化/禁令（92 处） | 绝大多数是确定性条款（答案区、题号、HTML 语法、载体、术语、计算）→ 保留；**唯一"反向钉死"**已改（错题本素材段头"一律自拟"，见四） | 只改反向钉死 |
| E 强角色/责任 | "署名编辑，对整体质量负全责…不达标即自行修订"是质量机制 | 不动 |

2. **反向钉死拆除**（`src/config/promptLibrary.js` 错题本素材段头）：
   "错题题干/变式的数据、情境、句式**一律自拟**，禁止沿用原文连续字面"
   → "错题题干与变式的素材口径见委托书【素材使用约定】"
   （理由：本项目自定"不写正向钉死、也不写反向钉死"，该处与原则自相矛盾；
   素材口径由【素材使用约定】单源承载：来源不限、不作指定 + 禁照搬通道无关。）
