# 三线生成架构 · 设计准绳（2026-09 复位）

本文件是 zhi-juan 生成架构的设计意图总纲，任何指令/素材/程序的改动都必须先过本文件再动手。
分线状态：委托线（已固话）、素材线（已固话）、底线线（已固话，2026-09-07 用户定版）。

## 系统脊柱：三条线，各守其位、互不越权

- 委托线（本文件已固话）：给模型一份精确、简约、三维度收敛的"委托书"——生成是主角。
- 素材线（待固话）：程序给模型"不诱导的料"——小份、按需、纯语义、无例题形态。
- 底线线（待固话）：确定性的由程序完成并接得住；语义设计的完全留给模型；程序不越位假装能查。

程序越把自己该懂的（确定性规格）收走，模型越能把自己该做的（编辑设计）做出来。
质量上限来自模型创造力释放，不来自任何一条线的检查。检查只是兜底，不是质量来源。

## 委托线使命（用户原话级复述 + 四根支柱）

使命一句话：系统通过"拼装"把三维度里最精确的那一份"委托书"交到模型手里——让模型像一位真正接到活儿的编辑：
一眼看清自己要做什么、为谁做、做到什么水准、可用的素材是什么，然后一次把它做好。

四根支柱（缺一不可）：

1. 架构可溯：每段注入内容来自哪个库、在哪层拼进、为何在此进入——不是黑盒堆叠，是装配图。
2. 三维度精确：注入判据只有一条——是否与"这个学科×这个学段×这个资料类型"真正相关。精确是排除的艺术，
   把与 cell 无关的挡在门外，留下的才可能干净。
3. 语义合规：进来的每段语义过两关——符合课标（按学段体系 2022 义教 / 高中 2017/2020），
   符合已固化审核基准（去诱导、单源、数据层措辞、宁缺毋滥……）。库件有错，注入再精确也是在委托书里种错。
4. 干净即委托，不是规章汇编：委托书只应有"这个活儿是什么、做成什么样算好"；
   事故教训沉淀在程序侧（它接得住的地方），不变成模型头上的禁令。委托书越干净，执行率越高——这是执行率的物理前提。

边界：委托线只负责"委托正确"；素材怎么给不诱导属素材线；程序接得住什么、替模型兜什么属底线线。

## 既成判定（用户已拍板，不可再犯）

- 指令是委托书，不是事故规章汇编；不因每发现一个问题就加一句提示语。
- 不给建议题型、不做例题骨架/题型化素材——给"要覆盖什么知识与能力"，永远不给"用什么题"（去诱导基准）。
- 模型是主编；程序是编辑助理，不是监工。
- 渲染契约语法、载体换算等程序性知识不属于委托正文（解释权在程序侧）。
- 角色合一说（2026-09-07）：编辑者与模型**双角色合一**——模型以编辑身份接手委托并完成稿件；程序是编辑的助手，不是验收方。全链去除"验收/打分/审计"思维；仅保留不可见的事故级护栏与编辑交稿前自校（覆盖自查由编辑本人在委托书内执行），不设外部验收角色。

## 素材线（2026-09 用户确认版 · 细化终版）

使命一句话：料是给模型查的，不是给模型抄的——小份、按需、不诱导；覆盖在取料侧有保底，不在出稿后补救。

双源两卡（预取 = 一个素材包，两卡来自两个源）：
- 依据卡：按本次覆盖锚行级裁剪的知识层级紧凑档（核心知识名 + 认知层次 + 具体概念整条保留 ≤4；建议题型与程序字段剔除）。依据 = 用户勾选范围 → 命中内容卡 → 锚树扁平 → 绑定过滤(missing 排除) 的确定性投影。
- 参考卡：锚绑定到的"示范段"的完整整段（教材例/结论框整段交付，**不切句不抽句**），预算化挑选（每锚 ≥1，多则按预算）；练习/作业型段不预取。

关键决定：
- 预取为主通道，浏览降级为按需追问（照搬防务在返回形态+护栏，不在调用方式）。
- 双区度量：委托书（指令区）恒定小、是"稀释"审计唯一对象；素材区（依据卡+参考卡）独立预算。素材区放正文之后显式分节（【素材·依据】【素材·参考】）。
- 供给决策矩阵：范围档（课/单元/多单元/整册）× 资料类型 → 契约模式 → 锚集 → 素材供给档。依据卡随覆盖锚集附（required 全锚 / sampled·focus 抽样锚）；整册 × required 属无解组合，契约层一票否决（拒绝或分批），素材包永不无界膨胀。
- 超预算降级次序：依据卡（覆盖保底）优先于参考卡；参考卡大范围可不全，缺的由 browse 补。
- browse：模型主动发起、仅限本次覆盖范围内锚（白名单校验，越界拒绝）；返回该锚未预取的绑定完整段（练习段仍不返回）；依据卡永不因参考缺失而缺。
- 可靠性三支柱：覆盖可靠=依据卡必须全，缺锚唯一合法出口是缺料诊断（不静默）；参考充分=预算内全量+浏览补全（不全不破坏正确性）；浏览边界=覆盖范围白名单。

红线（事实层零记忆兜底，2026-09 修正版）：
- 凡"教材怎么表述、课标怎么要求"的事实与依据，一律以【用户勾选教材原文】+【已固化课标要点（SUBJECT_STAGE_EXTRAS，版本受控）】为准；模型训练记忆不得补全/改写此类事实（教材可能改版、课标可能更新）。
- 该约束只作用于事实与依据的出处，不构成命题范围边界：情境、数据、设问、课外素材取材属创作层，可超越教材原文（须主题相关、难度适切、不超学段）。
- 一句话划界：教材原文是覆盖对齐的锚，不是命题宇宙的边界；模型记忆是创作的工具，不是事实的来源。
- 现状对应：coverageAnchor P0 红线（missing 不进可命题清单、进缺料诊断）保持并延伸到 Step1 分析与出稿修复层。

前置依赖（实现前盘点）：
- 锚范围性质判定：仅绑定"你知道吗/拓展框"型段的锚 → 拓展锚（不进必覆盖清单）；需 Step1 段类型枚举补"拓展/文化"类（现"你知道吗"可能落在 type=正文无法区分）。
- 锚命名校准（分析侧治理，防命名漂移影响依据卡/对账词面）。
- 语英 content 型卡形态（O1）：语文/英语教材正文多为课文/语篇而非规则句，preview/summary/dictation 所需"语料卡"形态待盘点语英 Step1 分析产物字段后定，不凭空设计。
- content 型全景上限（O2）与 browse 契约细节（O3）在实现期以 A/B 调档。

## 委托↔素材衔接：对话式多轮流程（2026-09-07 用户定版）

定性（用户原话级）：像与主编的对话——先充分了解素材，再追加委托使命；追加委托书消息 = 生成动作本身。

流程（用户视角三步 + 内部）：
- ① 勾选教材范围（现有界面）
- ② 【充分了解素材】（用户单按钮；内部 = 研读编排，见下）
- ③ 【下一步】= 追加委托书消息（注入指令那一步的等价物：现有指令面板/预览/编辑/类型与范围设置/生成参数全部保留照搬，只是时序后移到研读完成之后）；追加即触发**整份一次生成（一气呵成，不分段、不分块、不拼接、不续写）**
- ④ 出稿轻对账（质检面板保留，仅兜底）

铁律（多轮对话式步骤，2026-09-07 强化）：全流程**零注入，只有消息追加**——研读批=追加的用户消息、委托书=追加的用户消息、browse 返回=追加的工具消息（模型发起→程序返回→自动追加，非程序塞入）、正文/答案=模型消息。程序只做两件事：按状态机决定下一条消息、历史超长时压缩且替换（像长对话总结归档，绝不叠加）。任何阶段不构造、不预塞"给模型的内容块"。废除"程序分段分步生成"（分板块提示/分栏续写/两次生成拼装均属被否形态）；长度问题由单轮长输出能力承担（引擎选型/输出预算），绝不以分块提示绕行。

研读编排（内部，用户不可见细节，只显进度）：
- "充分"= 本次委托覆盖模式要覆盖的点集全部被研读且总账可溯源可校验（≠全读；模式决定读多深多广）。
- 批粒度自适应：命题型逐点精读批；梳理/总结型按章级/大概念级结构批。
- 每批：追加素材消息（该批覆盖点 + 绑定片段 + 课标要点）→ 模型消化产出批摘要（点名⊆该批清单、引用可溯源、非空，程序校验）→ 该批原文立即压缩替换为摘要（有界历史，峰值=单批大小）。
- 结束条件（状态机）：全部研读单元完成 + 批摘要合成"研读总账"（覆盖点全集↔每点摘要/引用）→ 程序校验通过 → 研读完成。missing 锚 → 缺料诊断，研读不静默通过。
- 研读行为模板 = 本产品生成模型应模仿的"编辑研读行为"：结构先行 → 目标驱动细读 → 分批增量消化 → 按需回查（browse 单点）→ 逐点对账 → 双向确认（模型回述理解，可提问澄清）。
- 逐点对账边界（2026-09-07 澄清）：对账只锁**事实/依据层**（知识语义、"教材怎么讲/课标怎么要求"的陈述必须可溯源，找不到就明说未提供，绝不冒充教材/课标如此）；**创作层**（情境、数据、设问、题型组织、课外取材）完全自由且课标鼓励超出教材（解决真实问题/综合应用）。对账防的是"假称教材/课标说过"，不是限制"题目内容出不出教材"。

预算与系数（2026-09-07 定版）：
- 成本模型两块：研读轮成本 = 批数×批大小×单价（系数=批粒度/批大小的调节旋钮，低系数粗读省钱、高系数精读）；生成轮成本 = 单轮输出预算。
- 完整性是硬约束、优先级最高：输出预算 ≥ 该类型×该范围完整篇幅（宁余勿缺）；现有"预期总量×系数→预算帽"机制保留但帽值以完整篇幅为底线；引擎最大输出仍不够 → 显式提示换引擎/确认，绝不静默截断；截断检测与重试兜底保留为最终防线。

承接关系：此流程取代旧"注入指令→生成"单步直灌模式；素材库资产（Step1 内容卡：知识层级+绑定）复用不变；实现前提 = 会话化编排器（消息数组+轮次状态机+压缩替换+browse 工具）。引擎（P1，2026-09-07 更正）：复用**应用设置中用户填写的引擎配置**（长上下文多轮+工具调用+长输出能力由该引擎承担）；端到端验证采用**应用内实操导出模式**——用户按复位后流程在应用内生成，导出产物与生成日志供审计（同本课 5 份文档的交接模式），不需要把 API Key 移交外部环境。

## 底线线（2026-09-07 用户定版）

使命一句话：确定性交给程序（它能接得住的部分），语义设计完整留给模型（它必须做好的部分）；程序不越位假装能查，模型不背程序性知识。

方法（自问两句，顺序不可反）：
- Q1 确定性判据：此项是否存在固定规则/词表/形式结构可判定？是 → 程序候选；否 → 模型职责，程序不得设"伪检测器"假装能查。
- Q2 接得住检验：程序接管前，模型侧必须产出什么稳定形态，程序才能确定性地处理？明确输出契约；接不住就改契约或不做，绝不硬查。

第一纪律（内容责任不可转移）：
- 成品的一切语义内容（题干、答案、栏目行文、情境、数据、设问、栏目组织）由模型单轮一次产出；
- 程序不得生成、补写、改写、重排任何内容——判定准绳："这段程序改了之后语义变不变，变了就是越权"；
- 程序只允许两类事：① 形态层确定性处理（纯标记层、不触语义：空位载体归一去重、○ 归一、<u> 整句兜底剥离、前言杂质兜底剥离、空白量补足）；② 校验与事实报告（发现问题→报告/回流模型重做/交编辑，程序端只报不改）。

程序绝不做的（越权红线）：不补写/改写/代生成任何内容；不给建议题型、不做骨架（去诱导）；不决定空位语义宽度；不判定语义雷同或"是否真考中"；不凭记忆补教材；内容层修复一律回流模型或交编辑。

无截断语义：上限管分批、不管切料——素材要么整段被研读/返回，要么作下一批继续，不存在被截掉的部分；生成输出预算 ≥ 类型×范围完整篇幅（宁余勿缺）；引擎最大输出不够 → 显式提示换引擎/确认，绝不静默截断；截断检测与重试兜底只做报告与重做。

空位宽度分层（2026-09-07 澄清）：语义定宽=模型（按答案内容与多解情形，答案等长则等宽否则按各自长度）；形态换算=程序（宽度标记→字宽×N 视觉尺寸/格子/行数，确定性）；校验兜底=程序只拦"整卷无差别等宽且过宽"，不做命题侧定宽判断。

开放项默认（2026-09-07 定，实现期校准）：
- O1 语英 content 型素材形态：实现前盘点语英 Step1 分析产物字段再定型，不空中设计；
- O2 研读单批上限=分批阈值（默认 ≤2500 字/批，超即拆批不切尾；完整性由批全集读完保证）；
- O3 browse 单次返回 ≤1 完整段（段内不切半，可多次查询、可查全集）；
- O4 载体补量仅限空白量（行数/留白），语义行永不程序生成；
- O5 防照搬护栏默认阈值：正文与参考段整句连续 8 字或同串 3 个数字命中即提示改写，A/B 校准。

三线齐（2026-09-07）：委托线管"委托正确且纯净"；素材线管"料可查不可抄、覆盖在取料侧保底"；底线线管"内容全归模型、程序只做形态/校验/报告/换算/编排"。
