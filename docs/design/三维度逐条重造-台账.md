# 三维度逐条重造 · 台账（2026-10-04 起）

> 依据：《[指令重造-执行文档-2026-10-04](指令重造-执行文档-2026-10-04.md)》（结果导向 · 应然判据表驱动 · 不依赖产物）。
> 走法：**同一资料类型的三维度做完，再做下一个资料类型；但一个一个过三维度**（学段/学科不同，要求不同）。
> 每个三维度产三件：①《应然判据表》②《逐条复核账》（每条×三问×处置）③ 改后指令＋守卫。
> 三问：**a 能不能保证应然某项(不足?) b 是不是判据式(按题型/方向=诱导?) c 是否与别条同义(稀释?)**

## #1 语文 · 小学低段 · 正式考卷

### ① 应然判据表（判据式；不写题型；**先问例外**）

**A. 内容自洽**

| # | 维度 | 判据（可自判） |
|---|---|---|
| A1 | 声明↔实给 | 卷面/题干/说明声明的（作答方式、数量、单位、分值、提示方式、载体）**真的给到**且形态吻合 |
| A2 | 题干↔答案↔解析 | 答案满足题干的形式性要求；解析与答案、题干一致 |
| A3 | 要素之间 | 同一处内部（题干、材料、选项、作答位、答案、说明、数据、称谓）互不矛盾 |
| A4 | 跨处一致 | 编号体系、同类作答位的位置与形态、术语与标注、符号与单位、同类写法——全篇一致 |
| A5 | 账目 | 空数×单价=大题分；大题之和=大类分；大类之和=满分；题数=实际给号数；单位与数值联动 |
| A6 | 材料/情境 | 数据/条件/对象足够且不矛盾；材料里**不出现待作答内容**（题干只给线索） |
| A7 | 层级↔内容 | 大类名、大题标题与其下实际内容/作答方式相符 |
| A8 | 唯一性 | 同型不重复设栏、同题子问不雷同（按考查作用判重） |
| A9 | 事实/教材口径 | 确定性事实与教材口径一致；不凭记忆断言、不混版本 |

**B. 载体自洽**

| # | 关系 | 判据（可自判） |
|---|---|---|
| B1 | 载体↔所填内容 | 填**符号**（字母/序号/√×）→ 括号空位；填**字/词/句** → 横线空位；写**汉字/词语** → 书写格；**成篇成文** → 作文格 |
| B2 | 载体↔位置 | 带选项的题：作答位在**材料与设问之后、选项行之前**（外语类题首）；材料内**缺处就地留空**、与题末作答位**并存** |
| B3 | 载体↔声明 | 题面声明的形态/位置/数量/工具（写在横线上、在田字格里写…），载体照声明给到 |
| B4 | 载体↔数量/宽度 | 一个空位一种载体；宽度随该空答案字位数；书写格数=该处字数；按空计分时空位数=计分单位数 |
| B5 | 载体↔就位 | 紧贴对应材料/题；不堆到题末、不另起一块、不预填答案 |
| B6 | 一致性 | 同卷/同题同性质空位形态与位置统一（不混用） |
| B7 | 不越权 | 不以文字充当留白；不给本不需作答的题硬加载体；表达类/写话类用作文格而非横线 |

**C. 本维度「例外」（先问、再记）**
- **C1**：选字/选词填空类，**允许用"（　）"括号空位**（低段语文卷惯例）；**判据**：同一题内形态一致、同卷同性质统一即可（**不强制一律横线**）。
- **C2**：书写格（田字格/米字格/拼音格）**只进语文低段**（学科×学段门控）。
