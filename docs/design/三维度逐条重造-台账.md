# 三维度逐条重造 · 台账（2026-10-04 起）

> 依据：《[指令重造-执行文档-2026-10-04](指令重造-执行文档-2026-10-04.md)》（结果导向 · 应然判据表驱动 · 不依赖产物）。
> 走法：**同一资料类型的三维度做完，再做下一个资料类型；但一个一个过三维度**（学段/学科不同，要求不同）。
> 每个三维度产三件：①《应然判据表》②《逐条复核账》（每条×三问×处置）③ 改后指令＋守卫。
> 三问：**a 能不能保证应然某项(不足?) b 是不是判据式(按题型/方向=诱导?) c 是否与别条同义(稀释?)**
> ⚠️ **记录纪律（2026-10-06 两次踩坑后立）**：本台账是**记录**，**不得复写单源规则字面**——守卫项见 `tests/config/singleSourceGuard.test.js`（扫描面含 `docs/design`）。引用这些规则时**用同义或加分隔**（如以"组织风格开关"指代开关、以"正规考试的卷面"指代该口径）。
> 🔴 **判据体检＝六问（2026-10-06 补第六问 · 起因见 ㉕㉖）**：①可自判 ②对象锚 ③口子 ④相抵·同义 ⑤松紧 **⑥该条涉及的每一"态"是否都有正句**（采用/未采用、空/非空、有/无、学段分叉、学科分叉、资料类型分叉、大类层设/不设、单题/多题、同型并列/独立设问、按空计分/混合分值…**缺一态＝缺一句**）。**每面体检必须显式列出该面"态清单"并逐态写"在位／缺→收口"**；缺态即**不得判"无缺口"**——防"平读代替矩阵"（**面 6 实证**：只写空态，"非空态"整支空着）。已写入唯一标准 `附·3 第 4 条`。

## #1 语文 · 小学低段 · 正式考卷

### ① 应然判据表（判据式；不写题型；**先问例外**）

**A. 内容自洽**

| # | 维度 | 判据（可自判） |
|---|---|---|
| A1 | 声明↔实给 | 卷面/题干/说明声明的（作答方式、数量、单位、分值、提示方式、载体）**真的给到**且形态吻合 |
| A2 | 题干↔答案↔解析 | 答案满足题干的形式性要求；解析与答案、题干一致 |
| A3 | 要素之间 | 同一处内部（题干、材料、选项、作答位、答案、说明、数据、称谓）互不矛盾 |
| A4 | 跨处一致 | 编号体系、同类作答位的位置与形态、术语与标注、符号与单位、同类写法——全篇一致 |
| A5 | 账目 | 空数×单价=大题分；大题之和=大类分；大类之和=满分；题数=实际给号数；单位与数值联动 |
| A6 | 材料/情境 | 数据/条件/对象足够且不矛盾；材料里**不出现待作答内容**（题干只给线索） |
| A7 | 层级↔内容 | 大类名、大题标题与其下实际内容/作答方式相符 |
| A8 | 唯一性 | 同型不重复设栏、同题子问不雷同（按考查作用判重） |
| A9 | 事实/教材口径 | 确定性事实与教材口径一致；不凭记忆断言、不混版本 |

**B. 载体自洽**

| # | 关系 | 判据（可自判） |
|---|---|---|
| B1 | 载体↔所填内容 | 填**符号**（字母/序号/√×）→ 括号空位；填**字/词/句** → 横线空位；写**汉字/词语** → 书写格；**成篇成文** → 作文格 |
| B2 | 载体↔位置 | 带选项的题：作答位在**材料与设问之后、选项行之前**（外语类题首）；材料内**缺处就地留空**、与题末作答位**并存** |
| B3 | 载体↔声明 | 题面声明的形态/位置/数量/工具（写在横线上、在田字格里写…），载体照声明给到 |
| B4 | 载体↔数量/宽度 | 一个空位一种载体；宽度随该空答案字位数；书写格数=该处字数；按空计分时空位数=计分单位数 |
| B5 | 载体↔就位 | 紧贴对应材料/题；不堆到题末、不另起一块、不预填答案 |
| B6 | 一致性 | 同卷/同题同性质空位形态与位置统一（不混用） |
| B7 | 不越权 | 不以文字充当留白；不给本不需作答的题硬加载体；表达类/写话类用作文格而非横线 |

**⑩ 找根因方法（2026-10-05 教训固化 · 全批通用）**

> 触发：同一现象**修过 N 次仍未根治**（本轮「大题下只挂一个小题＋小题标题复述」）。教训＝**不要再"改现象所在的那一处"就交差**。

1. **先做"同族横向扫"**：把该现象涉及的**关键词／同一要求**在全库**列点对照**（本轮列了 A1/A2/A3/A5、B1~B4、C1~C3、D1~D3 十三处），不是只修报障那处。
2. **专查"一个词两个义"**：同一词被两处当成不同对象 → **同名不同义＝必相抵**，这是"修 N 次不根治"的典型（本轮「题号」＝**作答单位** × **计分/展示单位**）。
3. **报告来的是现象，不是根因**：先归面 → 再问"**这条判据在同一份产物里会不会被另一处顶掉**"——不问这一句，就只会改一处。
4. **改完用该类关键词全库复扫**（本轮实测关键词：「全卷连续」「阿拉伯题号」「小题级」「题目以」）。
5. **三问自检**：这条判据在**同一份产物**里会被哪一条顶掉？换个学段/学科/类型会不会失效？我改的是**这一处**，还是**这一类**？
6. **禁枚举当边界**（用户 2026-10-06 定·我自己的违规纠正）：落笔前自问"**这句话里有没有枚举（举例）在当边界？**"——枚举＝**诱导**，且**覆盖不了开放集**：不在枚举里的，模型就当"不用做"。有就删、改**判据式**（举例如需保留，只作说明、不作边界）。实证：我在 `681a2fc` 写"其下不再另起小题号与题干行**（材料与作答位直接列出）**"——括号是枚举，只列"材料/作答位"，把"引出材料的**线索**"漏在外面 → 已删，回判据式；线索/作答位/载体各由既有判据式单源管（池 `#72`/`#73`/`#74`）。

> ⚠️ **更正（2026-10-06）**：我曾推断"拼音/格子丢失"由**上述枚举**造成。**取证未支持**：22:16 与 23:41 两份卷载体量相当（表格 2/2、下划线 29/27、加点 12/11），且 22:16 是**另一套卷**（大题一＝「游园会…选一选」），**不能作基线**；23:41 那份拼音确为 0，但空位载体在（27 处下划线）。本次"删枚举"**仅按原则执行**，不宣称其为该丢失的成因。
