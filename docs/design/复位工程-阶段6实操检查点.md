## 交互形态说明（如实，非 UI 两步按钮）

准绳用户视角三步（勾选 →【充分了解素材】按钮 →【下一步】注入指令）在实现中为"生成时自动前置"：
用户按原操作（勾选→生成指令→生成），程序在写作前自动执行研读轮（进度条显示"研读素材…批摘要核对"）。
计划阶段任务未含显式两步按钮 UI 改造；如需编辑先看研读结果再决定委托的两步交互，属后续 UI 项。

## 实操步骤（A 路径）

1. 应用内选择本课《小数乘法和除法（二）》（苏教版六上），资料类型=随堂巩固（practice），范围=本课。
2. 点【生成指令】（指令面板预览委托正文——应已不含渲染契约/质检规则段，比旧版更短更纯）。
3. 点【生成】，观察进度：应先出现"研读素材：编辑通读勾选教材（N 个覆盖点，分批消化+批摘要核对）…"，
   完成后进入整卷生成；生成日志出现 `[研读轮·会话式] X 批全部核对通过（回流 N 次）`。
4. 导出 5 份文档：产物 HTML、生成日志、操作指南、质量报告、注入完整指令（含程序附加段是否随日志呈现，
   若无请一并粘贴渲染契约 system 段内容——供审计）。
