## 一、任务

把**所有会发给模型的语义**，**逐条逐句**过一遍，做到：

1. **语义精准**——判据词、阈值、限定词、指向对象一字不失；
2. **表述简短**——每句读完都要能回答"能不能换个更短的写法"；
3. **以结果反推表述**——先想清楚"这份资料最终要呈现成什么样"，再倒推"该写哪条判据"；写出来的判据必须**可自判**（带对象／阈值／清单／算式），不得只有形容词；
4. **结构清晰**——段界分明、段内分层、一条一义、关键判据放首尾；
5. **同一份实发内不多块同义**——同一件事只留一处正句，其余**真引用**；
6. **遵守经检验仍成立的既定规则**——既有裁定先受检，不盲从、不照抄。

**产出**：逐句判定留痕（**顺序递进 ＋ 留痕完整**：该条 **8 项全落点**，逐项"过／不过（已处置）／不适用"）＋ 精简后的源文本 ＋ `npx vitest run tests/config` 全绿 ＋ 进度账更新。

## 三、执行标准

### 3.1 执行卡（**唯一对照面**：执行时只看这 5 条）

1. **一条一判：顺序递进 ＋ 留痕完整**。**递进**＝①是②的前提、②是③的前提……**前一问不过 → 先处置、再从中断处续判**，**不得越过未过的那一问去判后面**；**留痕完整**＝该条最终仍须有 **8 项全落点**，逐项写明"**过／不过（已处置）／不适用**"，**不得跳项不写**。二者不矛盾：**顺序递进、留痕完整**。
2. **判重＝判语义**（**作用结果相同即重复**）；**发现重复不得盲删**——先问三句：原先那条为何没执行到位／后条是否含前条没有的限定／删后靠什么防回潮。
3. **不省步**：不复用／不抽样／不凭印象／不按字面替语义／不机械切句；**任何"过完了／归零／无重复"必须附份 × 句进度账**。
4. **改完必做**：跑 `npx vitest run tests/config`；**跳转映射不得破**。
5. **业务取向判不了就问**（累积一起问）；其余**自判并留痕**，不得以"要用户点头"为由停顿。

### 3.2 八问（**用户口径 · 递进链，不得颠倒、不得跳问**）

① **三维度**：这条该不该出现在"这个学段×学科×资料类型"里？（不该＝越界，**优先门控、其次才删**；组合须**真实存在**）

② **课标**：按课标的地方——**原文还是原义**？限定词有没有被偷换？有没有编造？出处受控吗？

③ **啰嗦**：能否换成更短的写法？（同一件事说了几遍也算）

④ **精准**：换短之后，判据词／阈值／限定词／指向对象有没有丢或变？表述是否真的**指向了要产出的结果形态**（结果反推）？

⑤ **诱导**：有没有题型名暗示、设问／作答路径指定、自造举例、否定式植入？

⑥ **拼接**：与**同一份实发**里其他块拼起来，有没有重复、啰嗦、互相打架？（口径＝**同一份实发的完整装配内**，禁止跨份累计）

⑦ **排序**：指令的**位置与先后**，要符合模型遵守的习惯——
- 块内／库内先合：先契约后细则、**一段一主题**、段界分明、同主题相邻；
- 整份再合：**关键判据放首尾**（首尾注意力强、中段弱）、长素材不与判据混排、同判据不拆到各处、越靠近生成动作处放越关键约束；
- 现有体现：锚点清单在开头、委托正文末尾锚定、尾约束在最末尾、调用层自检插在尾约束之前。

⑧ **质量**：照这条发出去，产出的资料**能不能到高质量**？——无真机通道，须**标注判定层级**（纸面推演／程序校验／真机实测），**禁止无依据断言**。

### 3.3 判定权

- **自判**：①②③④⑤⑥⑦ 与"职责归属（要不要理解答案／内容）"等技术判定，一律自判并留痕。
- **才需问用户**：**业务取向**（产品形态、合规口径、学段学科真实性边界等）——**累积一起问**。
- **职责归属判据**：**程序只接"不需要理解语义即可确定性判定"的事**（账目算式、件序／占位、字符归一、页码分页）；**凡需知道"答案是什么／多长／内容是否自洽"的，一律归模型**。
- **正例样板**：**载体自洽＝模型主责 ＋ 程序兜底**（2026-09-30 用户裁定 G1）——提示词零新增、零题型名，是"能用程序确定性解决就不往提示词加字"的样板。

### 3.4 处置纪律

- **单源**：一判据一处正句，其余真引用（引用须指向真实注入的段，不得假指针）。
- **不得靠加字**：修复若靠新增一句，必须先删等量旧内容；新增前先归类（契约／判据／取向），**取向类默认不加**。
- **自检/复核类块＝补丁**：先定位它在替哪些前置指令兜底 → 把前置指令改精准、可自判、可直接照做 → 验证足够 → **才删**；**禁止以"再加一块自检"作为修复手段**。
- **改断言一律收紧**（属"改准"，不放宽），并写明依据。
- **零风险前置**（删任何东西之前）：先答"**删了会有什么风险**"；**程序接不住的一律不删**，不得盲目一刀切。
- **分三层定处置**：契约（协议/固定件，删了崩预览导出）／判据（须可自判）／**取向（可压成一句或删）**。

### 3.5 附条细则（**一律归在八问之下，不另立主条**）

1. **"真短"三要素**：**字数真减 ＋ 判据真减 ＋ 重复真消**——不是"没重复就算精简"。做法只有一条路：**逐条问"这句为什么在这儿"，然后有依据地删或移出**。凡称"已精简"，须留**原句 → 短句对照**。
2. **可自判锚**：判据不得只有形容词（"生动""合理"），须带可核对的对象／阈值／清单／算式。
3. **载体语义＝判据式**（不得用"许可式"）：不得写"由你按题干措辞与作答需要选定"；按"**所填内容是什么**"判——填符号（字母／序号／√×，含带选项的题）→ 圆括号空位；填短答（词／句／数）→ 横线空位；填成句成段→整行书写横线；抄写字词→书写格。并与"带选项的题一律圆括号空位"的硬约束**并成单一条款、单一裁决**。
4. **事故教训不写成禁令**：历史事故一律沉淀到**程序校验 ＋ 测试**，不以"严禁…"形式进提示词。
5. **超长即拆**：一条过长必须拆条，拆不动须留痕说明理由（**不设拍脑袋的字数线**）。
6. **引用必须真**：单源化后的引用须指向**真实存在且会被注入**的正句。
7. **术语唯一**：同一对象全库一个称法，新造术语须登记。
8. **课标必可溯**：凡课标相关须有 source 且受控——蓝图库 `stages.note` 的课标原文是**无出处受控的缺口**，处置＝补 source（保留原文）或按声明改准措辞，二选一，不得两套口径并行。
9. **语义重复的边界**：判准＝**作用结果相同即重复**；但**"原则句"与该原则的"落地细则"不算重复**（否则整套细则会被误删）。
10. **主次声明**：附条**一律归在八问之下**，不另立主条；理解一旦主次颠倒，执行就偏。
11. **附条来源分级**（防"把我的建议当成用户的裁定"）：
    - **【用户明示】**：八问内容与顺序、递进链、判重＝判语义、不得盲删、不省步、进度账、零风险前置、自检块＝补丁、载体判据式、业务取向才问、跳转不可破、对账"先归零再改"、结果反推表述；
    - **【我建议·默认通过（待实作验证）】**：分三层、可自判锚、事故教训不写禁令、超长即拆、一段一主题、引用必须真、术语唯一、课标必可溯、验收换标尺；
    - 🔴 后者**在首批实作中若不适用，必须提请修正**，**不得默认永久有效**。

### 3.6 验收方式

**沿用项目既有验收机制**（vitest ＋ 守卫 ＋ 真机抽样），**不另起体系**；但**改轨会改现状**——基线随之更新（属"改准"，不是"不许改测试"）。第 ⑧ 问无真机通道，须**标注判定层级**（纸面推演／程序校验／真机实测）。
