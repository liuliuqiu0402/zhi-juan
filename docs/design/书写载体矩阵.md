# 书写载体矩阵（9 类资料 × 载体 / 兜底 / 探针）

> 2026-09-26 建立。用途：把"什么形态的题该出什么书写载体、谁兜底、探针能否兜住"逐格列清，
> 避免再出现"判据假设与实际形态错位"的漏网（本轮已修三处，见第五节）。
> 标注约定：**✅已核实**（有代码出处 / 有测试）；**待核**（尚未逐条验证，下一轮补齐）。

## 一、载体标记清单（单一事实源）

| 标记 | 语义 | 渲染 | 事实源 |
|---|---|---|---|
| `<u class="blank-N">` | 填空**横线**空位（填词/句/数等短答） | `border-bottom` 画线 | `layoutSpec.BLANK_CARRIER_MARKUP.line`；`carrierCss` |
| `<span class="blank-N">` | **括号**空位（填字母/序号/√× 等符号） | 伪元素 `(` `)`，**半角** | 同上 `.paren`；`carrierCss` |
| `.blank-line` | **整行**书写横线 | 行内横线，可弹性延伸 | `carrierCss` |
| `.blank-area` | **无线留白**作答行（答题卡风格） | 按 `height` 留白 | `carrierCss`；`docxBuilder` |
| `zuo-wen-ge` | **作文格**（中文方块格） | 网格 | `themeConfig`；`contentCleaner` 空格补默认格 |
| `tian-zi-ge` / `mi-zi-ge` / `square-grid` / `bracket-grid` | 田字格 / 米字格 / 方格 / 括号格 | 网格 | `layoutSpec.WRITING_CARRIER` |
| `four-line-three` / `sixian-ge` / `pinyin-line` | 四线三格 / 六线格 / 拼音格线 | 格线 | 同上 |
| `square-box` / `math-circle-blank-N` | 数学**方框** / 比较**圆圈** | 1.8em 容器 | `layoutSpec`（数学专用通道）；`normalizeMathCircleBlanks` |
| `[IMAGE]` / `[GRAPH]` | 图标记（非书写载体，但属"作答依据"） | 渲染端出图 | `eduRenderContract` |

**选择规则（题类）**：`buildAnswerSpaceInstruction`（学科×学段注入）
- 带**选项**的题：形态**一律圆括号空位**（禁用横线）；**位置按学科**——外语类在**题首**、中文科目在**题干末尾**；半角括号（✅ 已修 + 测试）。
- 所填为**符号**（字母/序号/√×）→ 括号空位或圈作答；**短答**（词/句/数）→ 横线空位。
- 长答（成句成段）→ `ANSWER_REGION` 按学科×学段定：`line`（整行横线）或 `blank-area`（无线留白）。
- 数学算式缺数 → 方框/圆圈；比较大小 → 圆圈。

## 三、参数单一事实源（调参只改这里）

| 参数 | 位置 | 含义 |
|---|---|---|
| `ANSWER_REGION` | `layoutSpec` | 学科×学段 → `carrier`(line/blank-area) / `linePerScore`(每分行数) / `lineHeightMm` |
| `ANSWER_MAX_ROWS_BY_STAGE` | `layoutSpec` | 单题作答区**行数上限**（低段 4 / 中 5 / 高 6 / 初中 8 / 高中 8） |
| `ZUOWEN_FILL_CELLS` / `ZUOWEN_CELLS_PER_SCORE` | `layoutSpec` | 作文格：兜底格数 / 每分格数 |
| `BLANK`（`wordGap` 等） | `layoutSpec` | 空位宽度换算锚（1 字位 ≈ 1 em） |
| `WRITING_CARRIER` | `layoutSpec` | 学科×学段的格线载体（田字格/四线三格…） |

> 🔴 原则（既有裁定）：**调节点只有规格库一处**，补差逻辑里**不得加题型特例**。

## 四、本轮（2026-09-26）已修三处

| 现象 | 根因 | 修法 | 证据 |
|---|---|---|---|
| "连词成句"每题该 1 行却补 3 行 | `ANSWER_REGION` 语文·小低 `linePerScore=1.4` → 2分×1.4=3 行 | 语文·小低 **1.4 → 0.5**（仅改有实证者，中/高段与 `*` 通配不动）；封顶仍生效 | 测试 ⑦ 同文件 + `reportNoiseAndCarrierFixes` |
| "十六、看图写话"作文格没兜住 | 补格判据只认"数字开头小题"或"无编号带（X分）"，**且只遍历 `<p>`**；而正式卷写话是 **h2 汉字序号大题标题** → 三重落空、`debug` 静默跳过 | 判据补第三集合：**汉字序号大题/栏目标题（h2~h4）** | 正例 + **负例**（非写话汉字标题不得误补） |
| "要求：1./2./3."分条被逐条补作答位 | `2k` 把**所有数字开头段落**当顶层小题（`topPs`） | 加**保守双条件**判据排除分条（以「1.」开头 且 上一非空兄弟以"要求/提示…："结尾；续项一并排除）→ 作答位仍"整题之后、分条之后" | 测试：应 4 条（整题一处），非 6 条（逐条补） |
