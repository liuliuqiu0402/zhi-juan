## 5.1 程序介入点过尺（改了语义变不变？）

| 介入点 | 行为 | 判定 |
|---|---|---|
| `normalizeBlankMarkers` | ＿/（　）/裸下划线 → `<u class="blank-N">` 载体；密封字段行保护 | 形态层（书写空载体统一），不改文字语义 ✓ |
| `normalizeMathCircleBlanks` | 算式语境的 ○/□/占位 → square-box 填空框（题干"在○里填"后跟汉字不转） | 形态层（作答位归一，A-101 载体修复既定项）✓ |
| `normalizeMatchQuestions` | 连一连表格/列表 → match-question 结构（剥标签保留文本） | 形态层（匹配题呈现结构重组），文本不变 ✓ |
| `normalizeLeadingMarkers` | 段首剥离序号/要点符号（LEAD_SEQ/LEAD_BULLET） | 形态层（排版双重题号纪律）；正文粘连文字不受影响 ✓ |
| `normalizeIndents` | 移除内联 text-indent 与段首空白字符 | 形态层（防 CSS 缩进叠加加倍）✓ |
| `cleanSectionHtml` | markdown fence/body 剥壳/自审 div 移除/md 残留清理 | 形态层（容器清理）✓ |
| `stripPlanningPreamble` | 剥模型在正式内容前输出的计划性前言段（"我已获取教材原文…"） | 形态层（前言杂质清理，计划 5.1 点名项；有 6 用例护栏）✓ |
| `wrapBareBlankRuns` / `ensureCarrierContent` / `blankWidthForChars` | 空白段→横线载体、空位补 &emsp;、宽度换算 | 形态层（书写载体），补的是空白标记非文字 ✓ |
| `stripAnswerSection` / `stripLeadingAnswerTitle` | split 模式正文混答剥离、答案标题去重 | 形态层（位置/去重），不改答案文字 ✓ |
| `stripTypeWordFromTitle` | h1 标题移除命名规范外的类型词（试卷/考卷…） | 元数据层（标题命名纪律，非题目内容）✓ |
| 覆盖重试必覆盖点名 / 差异化要求注入 | 程序把上次缺漏考点名/已覆盖点注入委托 | 事实层供料（锚名为程序已知，非代写）✓ |
| 截断续写链 / 完整优先守卫 | 截断→同流续写→仍不完整判失败重做 | 兜底（准绳 90 保留），绝不静默截断 ✓ |
| 动态预算 clamp / engineCap 护栏 | 只收紧预算、超引擎上限提示换引擎 | 兜底（宁余勿缺）✓ |

结论：全链**无程序产生语义内容**的介入点；内容修复类均为纯标记/容器/结构层。
