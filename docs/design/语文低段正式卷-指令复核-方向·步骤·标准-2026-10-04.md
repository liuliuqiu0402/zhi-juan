# 语文·小学低段·正式考卷 —— 指令复核：方向 · 步骤 · 标准（2026-10-04 起）

> 定位：本文件记录**本次工作流的方向、步骤与标准**（用户口述、逐步补充），作为后续"出应然判据表 → 逐条审指令 → 改指令"的执行依据。
> 与既有标准的关系：`docs/design/任务-范围-执行标准.md`（唯一标准）优先；本文件只细化**本次范围＝小学低段（1-2年级）·语文·正式考卷**的做法。

---

## 一、方向（用户认可）

1. **以最终需要呈现的结果为导向**来写指令（先想清"这份资料最终该长什么样"，再倒推该写哪条判据）。
2. **审"指令"，不审"产物"**——不依赖产物对照（很多三维度**没有产物可对照**，教材原文尚未分析时更没有）。
3. 目标：指令**精准、简短、易执行**。
4. 约束（用户原话口径）：
   - **不能有任何诱导**（题型诱导词、指向性诱导词、各种属于诱导的）；
   - **不打补丁**；
   - **不限制模型能力**；
   - 除"生成资料所必须的指令文本"外，**不能有过多约束**（约束多了基调就定死 → 同质化）。
5. 有锁：**可以先解开，修改完再锁**。

---

## 二、应然的两大类：内容自洽 ＋ 载体自洽

### （一）内容自洽（当前 9 维）

| # | 维度 | 判据（可自判） |
|---|---|---|
| 1 | 声明 ↔ 实给 | 卷面/题干/说明里声明的（作答方式、数量、单位、分值、提示方式、载体）正文真的给到、且形态吻合 |
| 2 | 题干 ↔ 答案 ↔ 解析 | 答案满足题干的形式性要求；解析与答案、题干一致 |
| 3 | 要素之间 | 同一处内部（题干、材料、选项、作答位、答案、说明、数据、称谓）互不矛盾 |
| 4 | 跨处一致 | 全篇口径一致：编号体系、同类作答位的位置与形态、术语与标注、符号与单位、同类写法 |
| 5 | 账目 | 空数×单价＝大题分；大题之和＝大类分；大类之和＝满分；题数＝实际给号数；单位与数值联动 |
| 6 | 材料/情境 | 数据、条件、对象足够且不矛盾；材料里不出现待作答内容（题干只给线索） |
| 7 | 层级 ↔ 内容 | 大类名、大题标题与其下实际内容/作答方式相符 |
| 8 | 唯一性 | 同型不重复设栏、同题子问不雷同（按考查作用判重） |
| 9 | 事实 / 教材口径 | 确定性事实与教材口径一致；不凭记忆断言、不混版本 |

### （二）载体自洽（当前 7 判据）

| # | 关系 | 判据 |
|---|---|---|
| 1 | 载体 ↔ 所填内容 | 填符号（字母/序号/√×）→括号空位；填字/词/句→横线空位；写汉字/词语→书写格；成篇成文→作文格 |
| 2 | 载体 ↔ 位置 | 带选项的题：作答位在材料与设问之后、选项行之前（外语：题首）；材料内缺处就地留空、与题末作答位并存 |
| 3 | 载体 ↔ 声明 | 题面声明了形态/位置/数量/工具（"写在横线上""在田字格里写""用竖式"），载体照声明给到 |
| 4 | 载体 ↔ 数量/宽度 | 一个空位一种载体；宽度随该空答案字位数；书写格数＝该处字数；按空计分时空位数＝计分单位数 |
| 5 | 载体 ↔ 就位 | 紧贴对应材料/题；不堆到题末、不另起一块、不预填答案 |
| 6 | 一致性 | 同卷/同题同性质空位的形态与位置统一（不混用） |
| 7 | 不越权 | 不以文字充当留白；不给本不需作答的题硬加载体；表达类/写话类用作文格而非横线 |

### （三）第三类：质量 / 取向（**待用户定是否并列**）

充实、篇幅与容量相称、情境适切、思维含量、不超纲、唯一性等。
> 说明：这类更偏"取向"，并列进来更完整，但**加多了会变成约束/定基调**——是否并列、并列到什么颗粒度，待定。

## 三、标准（写指令时逐条遵守）

1. **穷举"情形面"**：每个自洽维度都要把需要覆盖的情形列全，才算"考虑全面"。示例：
   - 载体↔所填内容：符号 / 字·词·句 / 书写格 / 作文格 / 数学算式（缺数填数·比大小·结果位）/ 连线；
   - 载体↔位置：带选项 / 不带选项 / 书写格就地 / 长答集中一处 / 外语题首 / 中文题末；
   - 账目：按题 / 按空 / 按组 / 按字词 / 整栏一次计分。
2. **判据一律按"所填内容 / 位置 / 数量 / 账目"判**，**不按题型判**（按题型判即诱导）。
3. **一处正句＋其余引用**：同一件事只在一条写全，别处引用，消除多块同义（稀释）。
4. 改动**不靠加字**：先归类（契约/判据/取向），取向类默认不加；新增须等量删/并。

---

## 四、步骤（随讨论补充）

1. 出**「语文·小学低段·正式考卷」应然判据表**（两类/三类 × 穷举情形）——**先交用户审**，未审不落地。
2. 拿该表**逐条审**这一三维度实发的**全部指令文本**（指令库 + 蓝图注入 + system 程序附加段 + 用户消息侧其余块）——每条只问：
   - 这条判据**能不能保证**应然的某一项？（保不了＝不足）
   - 说的方式**是不是判据式**？（按题型/方向说＝诱导，改）
   - 和别条**是不是在说同一件事**？（重复＝稀释，收口）
3. 按"不足→补 / 重复→收口 / 按题型→改判据式"改指令；改后跑 `npx vitest run tests/config`。
4. 每一步留痕（台账）。
