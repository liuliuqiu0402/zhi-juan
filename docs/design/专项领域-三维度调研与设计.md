## 一、调研结论（本地代码取证）

### 1.1 通用专项结构现状（已事实清楚）

- 通用蓝本 `TEACHING_BLUEPRINTS.special` 只有两条栏目：**分板块组织**（按知识层级分板块，板块间由浅入深、层次依内容自然形成）、**每板块配解析**（讲明错因；聚焦本单元薄弱点）；五档学段各有 `note`，`volume`（题量档）**只作程序护栏、不注入 prompt**（`teachingBlueprints.js`；测试断言注入块不含数字区间）。
- 15 科都有 `special` 学科定制，差异仅在"分板块组织"的**板块划分口径**（语文/英语按本单元分板块；物理=概念辨析/规律应用/实验探究；化学=概念/化学用语/实验探究；…音乐=欣赏/表现/创造/相关文化；体育=动作要领/规则/健康知识…）。物理等 5 科另带初中/高中学段 note（无 volume）。
- `【教辅结构】` 是模板正文的**引用词**（`promptLibrary.js:188`：板块划分与题量按注入的【教辅结构】执行）；段头由两个生产者生成：通用 `【教辅结构（语文·专项突破·小学低段）…】`（teachingBlueprints）与领域版 `【教辅结构·专项领域：计算】…`（specialDomains）。模型侧无前缀识别器，拼写差异不影响，但两套格式需口径统一。

### 1.2 链路分流点（改造范围精确化）

- 领域/通用唯一分流点：`GenerateModule.vue:6068-6071`（`loadInstructionFromLibrary`），单次/多章/多类型/草稿为空四条生成路径全部命中。
- **遗漏点 ①**：`restoreDefaultInstruction`（「恢复默认」，:6159）无条件走通用蓝图，已选领域会被覆盖。
- **遗漏点 ②**：`userEditedInstruction=true`（用户手改过草稿）时切 `specialSubType` 不重装（:7913/:7945 守卫，watch 未含该键）。
- **口径差 ③**：领域版栏目行含 `(共X题)` 占位且段头写"题量按学段档"，但通用版注入不含题量、volume 不注入——两版口径不一致，需统一（去掉数字占位）。
- **文案残留 ④**：UI 内联两处（:1372 空态、:1397 通用选项副文案）未引用 `GENERIC_SPECIAL_DESC`（import 了没用）；`docs\生成链路与配方设计.md:51` 仍是旧四段式设计稿。
- 可生成矩阵：54 cell（学段×学科）全部可用 special（486 cell 预生成，无 special 白名单），`SUBJECT_STAGE_EXTRAS` 54 cell 每条带 source 可作为语义锚底线。

### 1.3 课标映射调研（外部检索，标题级，不抄条文）

- 体系隔离（CI 已固化）：义教学段 → 2022 义教课标；高中学段 → 2017 版（2020 修订）高中课标；两套同名不同义（如生物"探究实践/态度责任"vs 高中"科学探究/社会责任"）。
- 已拿到真实层级结构名（A/B 两级；B 级入库存前须以官方 PDF 复核，官方直链在来源清单）：数学（义教四领域，小学数与运算/数量关系、初中数与式/方程与不等式/函数…；高中必修五主题预备知识/函数/几何与代数/概率与统计/数学建模…）、语文（义教 6 任务群三层 + 四类实践活动；高中 18 任务群）、英语（主题范畴三大类 + 语言知识/技能要素）、化学（义教五主题原文）、物理/生物/历史/地理/道法（主题/板块/主题组标题，若干 B 级待核）。
- 留空待产品决策（无对应课标纸笔领域）：音体美表现/实践类、语文口语交际、英语听说、数学思维拓展(奥数)、高中实验大题（走素养落点）等。

## 二、设计规格（两档化终稿）

### 2.1 数据模型（`specialDomains.js` 重构）

```
学科
 └─ 领域 entry
     ├─ key / label / desc
     ├─ anchor       必填：课标语义锚（真实领域/任务群/素养名，如"数与代数·数与运算"）
     ├─ source       课标出处名（沿用 SUBJECT_STAGE_EXTRAS source 格式：'2022义教数学·…'）
     ├─ verified     'A'(已按官方PDF核对) | 'B'(待复核) —— B 不入生产注册表
     ├─ stageList    适用学段（五档直列，替代"小学/中学桶"粗略二分）
     └─ sections?    可选：A档=领域专属栏目(数组)；缺省=B档→结构走通用分板块，只注入锚句
```

- **A 档（自带栏目）**：仅"教学编排差异显著"的领域设栏目（计算/写作/几何等）。栏目行格式与通用蓝图统一：`· name——note`，**不含数字占位**。
- **B 档（仅锚句）**：委托注入 = 通用（学科）蓝图结构 + 追加一行 `· 本领域课标语义锚：…——命题遵守学科×学段课标要点`。

### 2.2 组合与注入（统一到一个 helper）

`composeTeachingText({genType, stageKey, subject, domainKey})`：
1. `domain = resolveSpecialDomain(...)`；无命中 → 通用蓝图（现状）；
2. 有 domain 且 `sections` 有值 → 领域版结构段；
3. 有 domain 但无 `sections` → 通用蓝图段 + 锚句行。

### 2.3 链路修复（实施清单）

1. `restoreDefaultInstruction` 改走 `composeTeachingText`（消除遗漏 ①）；
2. `specialSubType` 加入 watch 触发键，守 `userEditedInstruction` 语义：未手改自动重装；手改时给出"切领域需重新生成指令"提示（消除遗漏 ②）；
3. 领域版栏目行去掉 `(共X题)` 占位、去掉"题量按学段档"表述，与通用口径一致（消除 ③）；
4. UI 两处文案改引用常量（消除 ④ + 去掉无用 import）；
5. 旧设计稿 `docs\生成链路与配方设计.md:51` 更新为现行两栏目结构。

### 2.4 覆盖策略（不一次灌满矩阵）

- **T1**（随两档化同批）：语数英 × 5 学段——现 9 个领域种子做 schema 迁移 + anchor/source/verified 补全 + 学段直列（如语文文言文=初中/高中；英语语法=中高小起）。
- **T2**（盘点文档审后分批）：物理/化学/生物/历史/地理/道法 的 初中/高中 候选（调研草稿已有），B 级条目标注，入库存前按官方 PDF 复核。
- **T3**（产品决策后）：音体美/信息科技/科学；"留空清单"（口语/听说/奥数等）默认不出，字典占位禁选。

### 2.5 验收

- 全量回归 + 新增两档/锚句/restore 路径单测；
- 实生成 数学·计算（A 档）、语文·文言文-初中（A 档中学桶）、英语·语法（按学段起用）三份，注入来源面板应显示"领域名/栏目数或锚句/课标 source"；
- 注入文本抽查无数字题量占位、无旧四段文案。

## 三、风险与不变量

| 不变量 | 保证 |
|---|---|
| 不诱导 | 栏目=卷面组织语；anchor 只挂课标真名；不预设示范句/数据/情境 |
| 不虚构课标 | anchor/source 只录 A 级或 B 级标注；B 不入生产 |
| 学段隔离 | 高中锚走 2017/2020 高中课标名，不与义教同名混用（CI sourceControl 同机制） |
| 回退不伪造 | 未收录 学科/学段/领域 → 通用专项（含明确提示），不静默造领域 |
