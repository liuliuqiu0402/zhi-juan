# 教辅「学段要求」9 科草案（待审）

> 背景：三维度矩阵里，教辅的**学科级「学段要求」（`stages`）**目前只有 6 科（物理/化学/生物/历史/地理/思想政治，
> 恰为只在初高中开设的 6 科）。本草案补其余 **9 科**：语文、数学、英语、科学、道德与法治、信息科技、音乐、美术、体育。
>
> 判据（沿用既定规则）：**课标原文/原义 → 留；产品自造取向与形式词 → 清**（`bpWordingGuard` 钉的那条）。
> 每条 note 只作**语义锚**（描述"学生做什么"），**不规定内容组织方式**（2026-09-17 用户裁定）。
>
> 素材来源：教育部官方 PDF（**实测无文字层**）、地方转载 PDF（同样抽不出文字/个别已 404）、
> 教研全文转录与官方文件 HTML。凡未取得逐字原文处，一律标 **【待补】**，不自造填充。

## 一、落库写法（与现有 6 科同款）

```js
'语文': {
  stages: {
    primary_low: { note: '<课标学段要求摘要>（2022义教语文·三、课程目标→（三）学段要求）' },
    primary_mid: { note: '…（同章节）' },
    primary_high: { note: '…（同章节）' },
    middle:      { note: '…（同章节）' },
    // high 见第二节：高中用《普通高中课程标准（2017年版2020年修订）》
  },
  practice: { /* 栏目已存在，不动 */ },
}
```

- 结构：`stages[学段键].note`；**只写该学段实际开设的档**（如科学不写 `high`、道德与法治不写 `high`）。
- 出处：写"文件名＋章节"，与 `SUBJECT_STAGE_EXTRAS` 的 `source` 同口径。

## 二、档位映射（已定）

| 项目档位 | 语文 / 数学 / 道法 / 科学 / 信息科技 | 英语 | 音乐、美术（艺术课标） | 体育 |
|---|---|---|---|---|
| primary_low | 1–2 年级 | **地方课程**（京沪：起始一年级，一二年级以听说为主） | 1–2 | 水平一 |
| primary_mid | 3–4 年级 | 一级（3–4） | **3–5** | 水平二 |
| primary_high | 5–6 年级 | 二级（5–6） | **3–5 ＋ 6–7** | 水平三 |
| middle | 7–9 年级 | 三级（7–9） | **6–7 ＋ 8–9** | 水平四 |
| high | 高中课标（2017/2020 修订） | 高中课标 | 高中课标 | 高中课标 |

**音乐/美术取"跨段并列"**（艺术课标段为 1–2 / 3–5 / 6–7 / 8–9，与项目的 3–4 / 5–6 / 7–9 不同套）：
按"年级区间 ∩ 艺术课标段"取交集，跨段就并列；note 末注明"本档覆盖艺术课标 3–5 / 6–7 段"。
理由：就低归段会错档——`primary_high`(5–6) 归任一段都丢一个年级；`middle`(7–9) 归 8–9 丢 7 年级、归 6–7 丢 8/9 年级。

**科学**：1–9 年级打通，**不设 high 档**。
**道德与法治**：小/初开设，高中为「思想政治」→ 本表**不写 high**（高中档归「思想政治」，已有）。

| primary_low | 喜欢学习汉字，有主动识字、写字的愿望。认识常用汉字 1600 个左右，其中 800 个左右会写。／喜欢阅读，感受阅读的乐趣。学习用普通话正确、流利、有感情地朗读课文。学习默读。／学说普通话，逐步养成说普通话的习惯，有表达交流的自信心。 |
| primary_mid | 对学习汉字有浓厚的兴趣，养成主动识字的习惯。累计认识常用汉字 2500 个左右，其中 1600 个左右会写。／用普通话正确、流利、有感情地朗读课文。初步学会默读，做到不出声，不指读。学习略读，粗知文章大意。／尝试分类整理学过的字词，发现汉字形、音、义和书写的特点。 |

| middle | 能熟练地使用字典、词典独立识字。累计认识常用汉字 3500 个左右。／能用普通话正确、流利、有感情地朗读。养成默读习惯，阅读一般现代文每分钟不少于 500 字。／注意对象和场合，学习文明得体地交流。 |
| high | 【高中课标】语言积累与建构；语言表达与交流；增强形象思维能力（`普通高中语文课程标准（2017年版2020年修订）·课程目标`） |
