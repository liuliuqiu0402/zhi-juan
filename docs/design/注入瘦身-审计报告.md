# 注入瘦身审计报告（三维度：学段 × 学科 × 资料类型）

> 2026-09-14 ｜ 范围：54 科段 × 9 资料类型 = 486 组合 ｜ 原则：**语义不变，只压真冗余**

## 一、口径（用户定，逐条为验收红线）

| 红线 | 含义 |
|---|---|
| 语义不变 | 约束项（要求/禁令）一条不少；只压表达，不压要求 |
| 课标为首 | 课标学业要求、学科×学段要点是内容基准，不得为省字让步 |
| 不诱导 | 不得引入题型/内容诱导（项目有 `nonInducingPrompt` 等守卫） |
| 学科与学段特异表述不合并 | 54 个 cell 的差异是"三维度精准"的载体，不是冗余 |
| 资料类型不通用即分开 | 类型专属条款不得跨类型合并 |
| **不为简化而简化** | 只压"真需要压的"；密度已高的防错条款不硬压 |

## 二、方法

1. **全量枚举而非抽样**：对 486 组合逐条拼装"实际注入文本"，逐行枚举成条款台账（按文本指纹去重）→ **2023 条**，按"条款字数 × 出现组合数"加权统计覆盖率。工具：`ledger.mjs`（临时目录）。
2. **近义重复扫描**：同篇指令内句级 4-gram Jaccard 扫描（≥0.36 与 ≥0.45 两档），定位"不同措辞讲同一件事"的真冗余。工具：`near-dup*.mjs`。
3. **逐条对账**：每处改动给出"原要求 → 新句承载"的对应，确保要求不减。
4. **测试守卫**：改动后跑全量回归（124 文件 / 1740 测试，含 486 组合拼装审计：句级重复、类型不串味、课标逐条）。

## 五、判定"无需压缩"（附理由与证据）

### 5.1 全量扫描证据：无同义重复型冗余

| 阈值 | 结果 |
|---|---|
| Jaccard ≥ 0.45 | **0 对** |
| Jaccard ≥ 0.36 | 72 对，**去重后仅 1 个模式** |

唯一模式：同一篇指令内 TYPE 枚举出现两次（通用行 `TYPE ∈ BAR_CHART/…` 与学科段 `· 统计图（BAR_CHART/…，参数 …）`）。**判定不改**：括号那处另有"统计图=该三类型家族 + 参数清单"的映射作用，删除约省 40 字（0.7%），而样本行已含 `TYPE:BAR_CHART`，收益小、映射有丢失风险。

**结论**：剩余条款不存在"重复内容"型冗余。已省下的字来自"措辞层啰嗦"，不是重复。

### 5.2 按类型免审（不硬压）

| 类别 | 例 | 不压理由 |
|---|---|---|
| 程序协议句 | `<p class="question">`、`<u class="blank-N">`、`[GRAPH]` 参数名、`TYPE` 取值 | 程序↔模型接口，改字即断链 |
| 三维度特异内容 | 54 个学科×学段要点、学科事实底线（15 科）、学段特点 | 正是"不合并"红线；差异即价值 |
| 防错边界示例 | 题号连续性、空位形态统一、时态呼应、取整边界 | 每条都对应一类实测事故，删例即失守 |
| 蓝图明细/结构 | 教辅栏目名、卷面大题名与分值 | 数据不是措辞 |
| 渲染契约示例参数 | `LABELS/DATA/COLORS` 等样例行 | 契约自述格式，且为审计豁免项 |

## 六、剩余空间与建议

- **未审 67%**（约 4919 字/组合）。经 5.1 证据判断：其中**无重复型冗余**，可压空间只剩措辞层，估计上限 ~10%，且需要动到防错条款的精确度——**风险大于收益**。
- 若后续仍要减字，建议换手段（非压措辞）：
  1. **按需注入**：把仅在特定条件用到的示例（如 `[GRAPH]` 各 TYPE 样例）改为"命中该图形类型时才注入"；
  2. **注意力再分配**：程序协议句移入 system 注入（不减字，但减少正文被稀释）；
  3. **素材层**：`【压缩原文】` 是最大单项（整章原文），锚清单通道已默认不注入——这是省 token 的最大杠杆，方向已在既有设计中。
