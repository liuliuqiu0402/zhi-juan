# 智卷工坊 - 项目文件夹说明

本文档详细说明项目中各个文件夹的作用和内容。

---

## 📁 核心代码文件夹

### `src/` - 源代码目录
项目的核心前端代码，包含所有Vue组件和业务逻辑。

#### `src/components/` - 通用组件
存放可复用的Vue组件：
- `PdfPreview.vue` - PDF预览组件
- `RichTextEditor.vue` - 富文本编辑器组件

#### `src/composables/` - 组合式函数
Vue 3的组合式API封装，提供可复用的逻辑：
- `useActivation.js` - 激活码验证逻辑
- `useAiGenerator.js` - AI生成相关逻辑
- `useDialog.js` - 对话框管理
- `useFileHandler.js` - 文件处理逻辑
- `useTocParser.js` - 目录解析逻辑

#### `src/config/` - 配置文件
存放应用的配置信息：
- `apiConfig.js` - API接口配置（Ollama、DeepSeek等）
- `expertKnowledge.js` - 专家知识库配置
- `instructionLib.js` - 指令库配置
- `subjectContextLibrary.js` - 学科上下文库

#### `src/constants/` - 常量定义
- `events.js` - 事件常量定义

#### `src/modules/` - 功能模块
主要的业务功能模块（Vue页面组件）：
- `DraftModule.vue` - 草稿箱模块
- `GenerateModule.vue` - 智能生成模块
- `TemplateModule.vue` - 模板库模块
- `TextbookModule.vue` - 教材库模块
- `TypesetModule.vue` - 排版导出模块

#### `src/stores/` - 状态管理
Pinia状态管理store：
- `instructionStore.js` - 指令状态管理
- `templateStore.js` - 模板状态管理
- `textbookStore.js` - 教材状态管理

#### `src/styles/` - 样式文件
- `global.css` - 全局样式

#### `src/utils/` - 工具函数
通用工具函数库：
- `helpers.js` - 辅助函数
- `pathHelper.js` - 路径管理工具（存储路径配置）
- `qualityChecker.js` - 质量检查工具
- `requestManager.js` - 请求管理器
- `storage.js` - 本地存储工具
- `subjectValidators.js` - 学科验证器

#### 根文件
- `App.vue` - 应用主组件
- `main.js` - 应用入口文件
- `themeConfig.js` - 主题配置

---

### `public/` - 静态资源
存放不需要经过构建处理的静态文件：
- `icon.svg` - 应用图标

---

### `python-scripts/` - Python脚本
用于PDF处理和图像处理的Python脚本：
- `add_bookmarks.py` - 添加PDF书签
- `extract_outline.py` - 提取PDF大纲
- `pdf_text_extractor.py` - PDF文本提取
- `pdf_to_images.py` - PDF转图片
- `split_columns.py` - 分栏分割

**依赖管理**: 使用 `requirements.txt` 文件管理Python依赖

**安装命令**: 
```bash
pip install -r requirements.txt
```

**所需Python库**:
- PyMuPDF (fitz) - PDF处理
- pypdfium2 - PDF文本提取
- Pillow - 图像处理
- numpy - 数值计算
- opencv-python - 计算机视觉

---

## ⚙️ Electron相关文件

### `main.js` - Electron主进程
Electron应用的主进程代码，负责：
- 创建和管理应用窗口
- 文件系统操作（读写、移动、删除）
- Python脚本调用
- IPC通信处理
- 系统菜单配置
- 存储路径管理

### `preload.js` - 预加载脚本
在渲染进程和主进程之间建立安全桥接，暴露安全的API给前端使用。

## 💾 数据存储（运行时生成）

应用在运行时会创建以下数据文件夹（默认在用户文档目录）：

```
智卷工坊数据/
├── 教材库/              # 上传的教材文件
│   ├── 图片/           # 教材页面图片
│   └── 缩略图/         # 教材封面缩略图
├── 模板库/              # 教辅模板文件
│   ├── 图片/           # 模板页面图片
│   └── 缩略图/         # 模板封面缩略图
├── 生成历史/            # 生成的教辅历史记录
├── 导出/                # 导出的Word/PDF文件
└── 暂存区/              # 临时文件
```

**注意**：您可以在"系统设置"中修改存储路径到其他磁盘。

## 🎯 常用命令

```bash
# 安装依赖
npm install

# 启动开发环境
npm start

# 仅启动前端开发服务器
npm run dev

# 仅启动Electron
npm run electron

# 构建生产版本
npm run build

# 打包应用程序
npm run dist
```

## 💡 提示

1. **不要手动修改** `node_modules/` 文件夹
2. **不要提交** `dist/` 到版本控制（已在.gitignore中）
3. **数据存储路径**可以在设置中自定义，建议选择空间充足的磁盘
4. **Python脚本**需要安装Python环境和相关依赖才能正常运行
