# 智卷工坊 - 项目文件夹说明（2026-08 版）

本文档详细说明项目中各个文件夹的作用和内容。依据当前 master 实际目录编写（2026-08-29 核对）。

---

## 📁 核心代码文件夹

### `src/` - 前端源代码（Vue3 + Vite）

#### `src/config/` - 工具库体系（核心）
各库职责单一、不跨库，构成生成系统的"确定性知识层"：
- `promptLibrary.js` - **指令库**：生成注入指令，三维度（学科×学段×类型）675 内置模板
- `expertKnowledge.js` - **学科知识库**：15 科 canonical 清单、别名归一化、核心素养、学段要点
- `examPaperBlueprints.js` - **真题卷蓝本库**：exam 题型骨架/分值/时长唯一权威
- `teachingBlueprints.js` - **教辅蓝本库**：8 类教辅栏目框架/题量底线
- `validatorRules.js` - **规则库**：生成前约束 + 生成后质检修复（三维度过滤）
- `eduRenderContract.js` - **渲染契约库**：[IMAGE]/[GRAPH]/公式 标记协议
- `layoutSpec.js` - **排版规格库**：书写载体/作文格/方格纸（唯一事实源）
- `toolLibrary.js` - **工具库**：各库启停开关与三维度键注册
- `apiConfig.js` - AI 引擎配置（Ollama/DeepSeek、密钥 AES-GCM 加密）
- `analysisPrompts.js` - 教材分析 prompt
- `blueprintProvider.js` / `blueprintGuard.js` / `blueprintSchema.js` - 蓝图查询/校验/Schema
- `examRegionConfig.js` - 省市卷区配置
- `generationConstants.js` - 生成参数/预算/超时
- `paperScope.js` - 试卷范围推断/标题生成

#### `src/composables/` - 组合式逻辑
- `useAiGenerator.js` - AI 生成核心（唯一入口 generate → generateFullPaperNatural）
- `useActivation.js` / `useBackup.js` / `useDialog.js` / `useFileHandler.js` / `useLogger.js`
- `useMobile.js` / `usePullToRefresh.js` / `useTocParser.js` / `useWakeLock.js` / `useWebAuth.js`

#### `src/modules/` - 功能模块
- `TextbookModule.vue` - 教材库
- `TemplateModule.vue` - 模板库
- `GenerateModule.vue` - 生成编排（最大模块，指令组装/预览/导出）
- `DraftModule.vue` - 草稿箱
- `TypesetModule.vue` - 排版导出
- `GraphModule.vue` - 图形库
- `HistoryModule.vue` - 历史记录
- `SettingsModule.vue` - 设置
- `tools/ToolLibraryModule.vue` - 工具库管理（蓝图/指令/规则/渲染契约/排版规格视图）

#### `src/stores/` - Pinia 状态
- `templateStore.js` - 模板状态
- `textbookStore.ts` - 教材状态

#### `src/utils/` - 工具函数（纯函数，可测试）
- `docxBuilder.js` - Word 导出（含 htmlToDocxBlob）
- `examValidator.js` - 整卷质检
- `contentCleaner.js` - 内容清洗（含 stripXss 消毒）
- `rubyNormalizer.js` / `textSegmenter.js` / `wordExporter.js` / `contentCompress.js` / `libraryIO.js`
- `libToggles.js` / `pathHelper.js` / `requestManager.js` / `semanticRetriever.js` / `storage.ts`
- `helpers.ts` / `jsonParser.js` / `textRepair.js` / `instructionStyle.js` / `drawingMLShapes.js`
- `cloudStorage.ts` / `generationCache.ts` / `signatureCheck.ts`

#### 其它
- `src/components/` - 通用组件（RichTextEditor、PdfPreview、CompareView、AppDialogs 等）
- `src/router/` - 路由
- `src/styles/global.css` - 全局样式
- `src/constants/events.js` - 事件常量
- `src/themeConfig.js` - 排版主题
- `src/App.vue` / `src/main.js` - 根组件/入口

## 💾 数据存储（运行时生成）

应用运行时在用户文档目录创建数据文件夹（可自定义路径）：

```

├── 教材库/              # 上传的教材文件（图片/缩略图）
├── 模板库/              # 教辅模板文件
├── 生成历史/            # 生成的教辅记录
├── 导出/                # 导出的 Word/PDF
└── 暂存区/              # 临时文件
```

## 🎯 常用命令

```bash
npm install       # 安装依赖

npm run dev       # 仅前端开发服务器
npm run test      # 运行全部测试（520 用例）
npm run build     # 构建生产版本
npm run dist      # 打包 Electron 安装包
```

## 💡 提示

1. **不要手动修改** `node_modules/`
2. `dist/`、`release/`、平台构建产物**不提交**（已在 .gitignore）
3. PaddleOCR 模型为本地文件，不入库
4. 新增/改名学科或类型时，遵守各库顶部"🔗 命名双轨"注释同步
