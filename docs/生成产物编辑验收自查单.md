# 生成产物·编辑验收自查单（真实模型输出对照用）

> 用途：你在产品里生成一份资料后，如何判断"是否达到编辑者要求"。对每份产物按四问打分：
> 判定口径：红 = 必改（这份不能算合格）；黄 = 建议改进（不影响成立）；绿 = 通过。
> 配套先看：产品自带"质检提示"面板（问题列表/抽检条目）非空时逐条对照；本单用于人眼复核它兜不住的语义项。
> 覆盖口径：正文实际呈现才算覆盖——声明"覆盖了…"不算（覆盖只以实际题目/条目计）。

## 一、覆盖对账（第一步，先做）

1. 打开该份资料对应的"本资料须覆盖的核心知识"清单（随生成请求的勾选/知识树）；
2. 逐项在正文里找题（搜索关键词或按题号定位）：每项至少被一道题/一个任务实际考查；
3. 缺一项 → 红。注意：required 型（课时练/试卷等）不允许整点遗漏；focus/sampled 型按主题选点属设计内。

## 二、Q1 编辑要素（内容 + 排版）

- 题号连续无跳号；无"空条款"（只有题号没内容，如"3．。"）；段落独立成 <p>，无多题堆叠；
- 每题都可作答：任务词与作答形态匹配——说"选择/选一选"必有选项、说"判断/对的打√"留有 √× 空、说"填空"有空位、说"写在横线上/格子里"有对应书写位、长答有整行横线或留白；
- 载体不裸奔（形态由模型按题干措辞选定，2026-09 定稿不强绑，此处只查"真实存在+任务词自洽+同卷同题型一致"）：填空空位真实可写（常态为下划线空位或与题干一致的空位形态）、选择/判断是括号空（　）或圈作答、数学竖式/作图有专用书写区、写话/作文有书写行或作文格、英语抄写有四线三格（中低段）、拼音有拼音格/括号注音（低段）；空位宽度按答案长度换算、同一题同性质空位形态一致、一个空位只呈现一种载体（禁横线+括号叠用）；
- 分值账目自洽（试卷/带分教辅）：小题数×每题分=大题分、各大题之和=满分；小题标题标"(X分)"。

## 三、Q2 冗余 / 矛盾

- 全文无整段/整题重复（尤其卷尾截断重出）；相邻题不雷同（同情境同数据同设问）；
- 同一题只有一个作答载体（不横线+括号叠用）；答案区不把正文梳理整体复述一遍；
- 题干文字没有整句下划线/删除线修饰（画线只用于题干点名的"画线句子"并带对应标记）。

## 四、Q3 课标与数据

- 可数对象只用正整数个数（禁"0.86 张（即 86 张）"式双量写法）；单位换算数值与单位同步改（禁"2.05 千米=205 千米"式只改数不改单位）；
- 难度不超学段（低段不出现未学概念/抽象符号；不超前引入高段知识；试卷不超学业质量要求）；
- 理科数据与答案自洽（能正向由前提推出）；图表/配图描述与题干严格一致、图内无字不暗示答案。

## 五、Q4 基准红线（一眼红速查）

- 出现"答：""作答区"当作答位 → 红（必须真实留白或载体，空标签不算作答空间）；
- 出现"由排版层补足/渲染层负责/程序自动补"类表述进正文 → 红；
- 出现【插图占位】等模板残留、被转义的标签（\</div\>）→ 红；
- 知识卡/总结里把正文梳理整体复制进答案区 → 红（答案区只作答题目）；
- 题内预填了答案或格子内写了字 → 红（作答位必须留空）。

## 六、各资料类型侧重（四问之上，类型专项）

| 类型 | 专项必查 |
|---|---|
| exam 正式卷 | 卷首标题/时长满分/密封线（含姓名学校学号栏）；大题标题带题量与分值；听力/阅读题给全材料（听力原文与录音说明进答案区）；材料题选文标注出处 |
| practice 课时练 | 三任务结构（基础建构→探究进阶→迁移创新）；任务情境完整可做；变式不只换数字 |
| special 专项 | 板块内由易到难；解析讲"错因—如何避免—正确思路" |
| preview 预习 | 任务写明"做什么+怎么做+完成标准（可自查）"；含"我的疑问"栏目 |
| reading 阅读 | 选文原创无语病、完整不截断；设问不能直接在原文找现成答案 |
| summary 总结 | 结构化呈现；每个知识点给内涵/适用前提/易错；典型例题即时带解析（不设作答空） |
| dictation 默写 | 严格对应教材要求；内容在语境中呈现（不孤立罗列） |
| errorbook 错题 | 归因具体到知识点/思维环节；每题 1 道同类变式 |
| review 复习 | 知识网络化；梳理标注教材出处；自测分层覆盖本单元 |

## 七、判定与留痕（每份一行）

```
资料：{类型|学科|学段|单元}  日期：____  引擎/模型：____
覆盖对账：命中 __/__ 项（缺：____）
Q1：红__黄__绿   Q2：红__黄__绿   Q3：红__黄__绿   Q4：红__黄__绿
结论：□通过（红=0） □返工（列出红项）
红项是否暴露生成侧规则缺口：□否 □是（描述，可报回固化 CI/提示词）
```

## 八、口径提醒

- 单份通过 ≠ 永远达标：模型输出有随机性；合格标准是"本份红=0 + 缺漏可被检出"；
- 发现红项建议先看是否为个例（重生成一次即可），若同类红项反复出现 → 是生成侧规则缺口，报回补充（提示词/CI 都可增量）；
- 判定时以"编辑看到这份能不能直接出版/下发"为直觉基准，不因"是 AI 生成的"而放宽。
