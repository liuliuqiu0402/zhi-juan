# 智卷工坊 - 打包发布指南

## 📦 打包步骤

### 1. 构建前端
```bash
npm run build
```

### 2. 打包Electron应用
```bash
npm run dist
```

生成的安装包位于：`release/智卷工坊 Setup X.X.X.exe`

---

## 🔧 用户安装后配置

### **必需条件**

用户在运行智卷工坊前，需要：

1. **安装 Ollama**
   - 下载地址：https://ollama.com/download
   - 支持 Windows/macOS/Linux

2. **下载所需模型**
   ```powershell
   # OCR多模态模型
   ollama pull qwen3-vl:8b
   
   # 文本生成模型
   ollama pull qwen2.5:7b
   ```

3. **启动 Ollama 服务**
   - 方式1：从开始菜单启动 Ollama
   - 方式2：命令行运行 `ollama serve`

4. **验证 GPU 加速（可选但推荐）**
   ```powershell
   ollama ps
   ```
   应该看到 `PROCESSOR: 100% GPU`

## ⚙️ 应用启动流程

## 🎯 常见问题

### Q1: 为什么提示"Ollama 服务未运行"？
**A**: 需要先启动 Ollama 服务。从开始菜单找到 Ollama 并启动，或在命令行运行 `ollama serve`。

### Q2: AI 响应很慢怎么办？
**A**: 检查是否启用了 GPU 加速：
```powershell
ollama ps
```
如果显示 `100% CPU`，说明没有使用显卡。解决方法：
- 确保安装了 NVIDIA 驱动
- 重启 Ollama 服务
- 检查显存是否足够（RTX 4060 8GB 足够）

### Q3: 如何确认使用的是 GPU？
**A**: 运行 `ollama ps`，查看 `PROCESSOR` 列：
- `100% GPU` → ✅ 正确
- `100% CPU` → ❌ 需要排查

### Q4: 可以更换其他模型吗？
**A**: 可以。修改配置文件 `resources/app.asar.unpacked/src/config/apiConfig.js` 中的模型名称，然后重新下载对应模型。

## 📋 系统要求

### 最低配置
- **操作系统**: Windows 10/11 (64位)
- **内存**: 8GB RAM
- **存储**: 20GB 可用空间（模型占用约15GB）
- **GPU**: 集成显卡（CPU模式，速度慢）

### 推荐配置
- **操作系统**: Windows 10/11 (64位)
- **内存**: 16GB RAM
- **存储**: 30GB 可用空间
- **GPU**: NVIDIA RTX 3060 或以上（8GB+ 显存）

## 🔍 故障排查

### Ollama 无法启动
1. 检查是否已安装：`ollama --version`
2. 检查端口占用：`netstat -ano | findstr :11434`
3. 重启电脑后重试

### 模型下载失败
1. 检查网络连接
2. 使用国内镜像（如有）
3. 手动下载：https://ollama.com/library

### GPU 不生效
1. 更新 NVIDIA 驱动到最新版本
2. 重启 Ollama 服务
3. 检查 CUDA 版本兼容性
