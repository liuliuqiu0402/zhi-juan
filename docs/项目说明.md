智卷工坊 · 项目说明书
产品定位
智卷工坊是一款面向小初高教师的学科教辅智能生成系统。它能够基于教师上传的教材和教辅模板，通过AI理解内容并生成对标正式出版物的高质量资料（试卷、课时练、知识点总结等）。

核心价值
降本增效：将教师从重复性劳动中解放，3分钟生成一份高质量教辅

精准对标：严格基于教材内容和模板风格，AI不瞎编

本地化部署：支持Ollama本地模型，数据安全可控

专业化排版：内置多种专业排版主题，一键导出Word/PDF

目标用户
小初高各学科教师

教育培训机构

学校教研组

教辅出版机构

系统要求
Windows 10/11 64位

内存：8GB以上（推荐16GB）

硬盘：10GB以上可用空间

显卡：支持CUDA的NVIDIA显卡（可选，加速AI推理）
