# 智卷工坊 · 项目说明书

## 产品定位

智卷工坊是一款面向小初高教师的学科教辅智能生成系统。它能够基于教师上传的教材和教辅模板，通过 AI 理解内容并生成对标正式出版物的高质量资料（正式试卷、课时练、知识点总结等 8 类教辅）。

## 核心特性

- **三维度匹配**：生成内容严格按 学科 × 学段 × 资料类型 三维度注入，无跨学科/跨学段/跨类型污染
- **新课标合规**：命题依据 2022 义教课标 / 2017（2020 修订）高中课标，核心素养逐字引用、可查可引用
- **正式卷可直接用**：试卷含密封线、题号层级、分值、评分标准、听力原文等全要素，命题老师视角可直接用于考试
- **8 类教辅**：课时练/专项突破/课前预习/阅读训练/知识总结/默写积累/错题本/复习资料，栏目框架齐全可用于教学
- **程序/模型分工**：程序能确定性计算的（分值/载体/质检/兜底）全部代码化，prompt 只承载模型需要理解的语义

## 核心价值

- **降本增效**：将教师从重复性劳动中解放，3 分钟生成一份高质量教辅
- **精准对标**：严格基于教材内容和模板风格，AI 不瞎编
- **本地化部署**：支持 Ollama 本地模型，数据安全可控
- **专业化排版**：内置多种专业排版主题，一键导出 Word/PDF

## 目标用户

- 小初高各学科教师
- 教育培训机构
- 学校教研组
- 教辅出版机构

## 系统要求

- Windows 10/11 64位
- 内存：8GB 以上（推荐 16GB）
- 硬盘：10GB 以上可用空间
- 显卡：支持 CUDA 的 NVIDIA 显卡（可选，加速 AI 推理）

## 技术栈

- Vue 3 + Vite + Pinia + Tiptap（富文本）
- Electron（桌面端，PDF 导出用 Puppeteer）
- Capacitor（Android/iOS 移动端）
- Vitest（520+ 单元测试）
