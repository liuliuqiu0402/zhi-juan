📁 智卷工坊 · 项目结构

wisdom-workshop/
│
├── package.json                 # 项目依赖配置
├── vite.config.js               # Vite 构建工具配置
├── electron-builder.json        # Electron 打包配置
├── start.bat                    # 一键启动开发环境
├── preload.js                   # Electron 主进程  # 🔗 预加载脚本：暴露 API 给渲染进程（文件操作、加密）
├── package-lock.json            # 依赖版本锁定文件，由 npm install 自动生成，记录所有依赖包的精确版本号，确保换电脑重装时依赖版本完全一致
├── main.js                      # Electron 主进程  # 🔧 主进程入口：窗口创建、IPC通信、PDF处理、机器码
├── install.bat                  # 一键安装依赖
├── index.html                   # 应用入口 HTML 文件，Vite 构建时的起点，定义页面标题、图标引用和 <div id="app"> 挂载点
├── create_thumbnail.py          # 缩略图生成脚本（Python），用 PyMuPDF 读取 PDF 的第一页并转为小尺寸 PNG 图片，用于教材/模板的封面缩略图
├── build.bat                    # 打包构建脚本，一键执行 npm run build（构建前端）和 npm run dist（打包 Electron 安装包），生成可发布的 .exe 安装程序
├── 激活码生成器.html
│
├── python-scripts/              # Python 辅助脚本  独立管理
│   ├── pdf_to_images.py         # 🖼️ PDF 转图片（教材/模板预览图生成）
│   ├── add_bookmarks.py         # 📑 给 PDF 添加目录书签
│   └── extract_outline.py       # 📖 从 PDF 中提取目录结构
│
├── src/                         # 前端源码
│   │
│   ├── main.js                  # 🚀 Vue 应用入口：挂载 Pinia、Router
│   ├── App.vue                  # 🏠 根组件：激活验证、引导页、主布局、指令库/历史/图形库
│   ├── themeConfig.js           # 排版导出模块的主题配置文件，包含15个预设排版主题的字体、字号、颜色、间距样式，以及智能标题识别规则和自定义主题的增删改查逻辑
│   │
│   ├── config/                  # ⚙️ 配置文件（工具库体系，各库独立不跨库）

│   │   ├── expertKnowledge.js   # 🎓 学科知识库：学段/学科/题型/核心素养/认知层次/超纲边界/术语规范
│   │   ├── promptLibrary.js     # 📋 指令库：生成注入指令（三维度：学科×学段×生成类型）

🔗 核心数据流

用户上传 PDF
    ↓
TextbookModule/TemplateModule
    ↓ pdfToImages (Python)
图片文件存储到本地
    ↓
用户勾选章节 → 生成指令
    ↓
GenerateModule → buildGenerationInstruction()
    ↓
useAiGenerator.generate()
    ├── Step 1: extractContentCards()     # AI 提取命题素材
    ├── Step 2: buildKnowledgeMap()       # AI 构建知识图谱
    ├── Step 3: 生成命题蓝图              # AI 规划题型/知识点/难度
    ├── Step 4: 逐题生成                  # AI 逐题命题 + 硬性验证 + 交叉验算
    └── Step 5: 多维度质量校验            # 格式/覆盖率/超纲/AI 审查
    ↓
用户确认蓝图 → 生成最终文档
    ↓
TypesetModule → 选择主题 → 导出 Word/PDF
