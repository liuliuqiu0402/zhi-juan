## 核心数据流（2026-08 版）

```
教材/模板 PDF → 上传 → 教材分析（AI）→ 章节/知识点
    ↓
用户勾选 → GenerateModule 组装指令（指令库×蓝图×规则库三维度注入）
    ↓
useAiGenerator.generate()  ← 唯一生成入口
    ├── 正文整卷生成（generateFullPaperNatural，一次调用）
    ├── 答案页段（exam 走 split 两次生成；教辅 once 一次成型；空壳剥离/失败降级/截断续写护航）
    └── 后处理（标题清理/密封线兜底/整卷质检 auditExamPaper）
    ↓
结果入库（HistoryModule）→ TypesetModule 排版 → 导出 Word/PDF
```
