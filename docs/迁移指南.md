智卷工坊 · 迁移指南（换电脑/重装系统）
# 一、备份旧电脑数据
备份数据目录

复制整个 D:\智卷工坊数据\ 文件夹到移动硬盘或U盘

备份软件配置（可选）

复制 C:\Users\你的用户名\Desktop\wisdom-workshop\ 整个文件夹

# 二、新电脑环境准备
安装 Node.js

官网下载：https://nodejs.org/

推荐版本：v18 或 v20 LTS

安装 Python

官网下载：https://python.org/

推荐版本：Python 3.11.x

安装时勾选「Add Python to PATH」

安装 Ollama

官网下载：https://ollama.com/

安装后打开，等待服务启动

下载 AI 模型

cmd
ollama pull qwen3-vl:8b
ollama pull qwen2.5:7b
# 三、恢复软件和数据
复制软件文件夹

将备份的 wisdom-workshop 文件夹复制到新电脑桌面

恢复数据目录

在D盘创建 D:\智卷工坊数据\ 文件夹

将备份的数据复制进去

安装依赖

进入 wisdom-workshop 文件夹

运行 install.bat

启动系统

运行 start.bat

# 四、重新激活
打开软件，记录显示的机器码

使用「激活码生成器.html」生成新的激活码

输入激活码完成激活
