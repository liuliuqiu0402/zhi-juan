## 二、两处需核项的取证与裁定（回原文逐字）

**A｜美术-high·`practice` 越学段（**真错·成立·已修**）**

- 〔栏目〕`practice-美术-high:140-142`：
  · `基础建构——【要求·须逐项落实】**审美感知（欣赏·评述）**：涉及本次范围造型/色彩/构图等核心内容，结合实例考查`
  · `探究进阶——…**艺术表现（造型·表现）**：表现与创作题目`
  · `迁移创新——…**创意实践与文化理解（综合·探索）**：欣赏评述与生活应用，联系本单元主题`
- 〔同件声明〕`:139`"栏目的**内容归属参考**《**普通高中**课程标准（2017年版2020年修订）》的活动类型与素养"；`:148`【学段要求（高中）】"高中美术学科核心素养（**图像识读/美术表现/审美判断/创意实践/文化理解**）"
- 裁定：**真错（成立）**。逐字核对：栏目首词"**审美感知／艺术表现**"是**义教艺术课标**素养名、括注"**欣赏·评述／造型·表现／综合·探索**"是**义教美术学习领域**名，**均不属高中美术** ⇒ 与同件"参考《普通高中课程标准》"**字面相抵**、与同件高中素养名**不一致**。
- 根因：该 `practice` 栏目为**学科级共用**（`teachingBlueprints.js` 的 `stages` 只存"要点"，栏目不分档）⇒ 义教专属名被注入高中面。
- **已修**：三条 note 去掉**学段专属名**（只留"考什么"）——`涉及本次范围造型/色彩/构图等核心内容，结合实例考查`／`表现与创作题目`／`欣赏评述与生活应用，联系本单元主题`。
- 修法依据（守"只促规范·净字不增"）：① 具体素养名**已由按学段的【学段要求】块单源给出**（高中面给高中素养、义教面给义教素养），栏目再列一次＝**两处口径**，正是本缺陷之源；② 中性化后**对义教/高中一律成立**；③ **净减字**。

**B｜美术-primary_mid·`exam` 缺【学段要求】文本 → 降级（非 prompt 缺陷）**

- 与已结案口径一致：**全库 54 份 `exam` 快照均不含"学业要求（第N学段）"（0 命中）** ⇒ `exam` 以【卷面结构／命题蓝图】为**依据**属**设计**（该判断已在前批固化）；补它＝净字大增（四问④）⇒ **降级**。
