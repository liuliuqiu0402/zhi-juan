# 核证判法（单源）·促规范 vs 过度约束

> 适用：**每一片**的核证（54 片）与我方对复核建议的取舍。**属主口径（2026-10-13）**：
> "目标是输出**高质量的各类型资料**；而且是**无限次生成**的，所以**不要过度约束，而只是促规范**——约束太多就是定死了，必然**同质化**。"

## 一、总原则

**约束只落在"合格线"（可判的边界）；"怎么选"留给模型。**
合格线＝"不合格能被指出来"（例：两处可互相替代＝重复；声明与实给不符＝错）。
越线＝"把一种做法写成唯一做法"（例：题量下限、指定情境来源、指定题型顺序、指定具体栏目名/示例名）。

## 二、每条建议过四问（**四问全过才采纳**；任一不过 ⇒ 驳回或降级）

| # | 问 | 不过就驳回的情形（举例） |
|---|---|---|
| ① | **是"规范"还是"定量/定形"？** | 出现具体数量下限／上限、指定唯一形态、指定具体名称或示例名 ⇒ 属定形定量 |
| ② | **是否在依据内？**（本学段课标／本类型定位／本次已注入依据） | 依据外要求（如小学段要求"代码书写"）⇒ 越权约束 |
| ③ | **是否会制造"逐字相同"的复制面？** | 给具体例子／具体成品名／固定句式 ⇒ N 份产出同形 ⇒ 示例应给**结构占位**（〈栏目标题〉）而非成品 |
| ④ | **净字是否不增？**（改条不新增条、净字只减不增） | 加解释性补注、加元话语 ⇒ 驳回（项目已有"去元话语"口径） |

## 四、项目**已内置**的防同质化机制（改条时不得削弱；逐字）

1. 素材来源留白：`情境、素材、人名、数据与句式可取自教材，也可取自课外真实生活（与本资料主题一致、难度合本学段），**来源不限、不作指定**`
2. 组织留白：`分组依据与组名都由你按本部分内容**自行定（不作指定）**`
3. 形态多样：`【尾约束·资料内多样】同一份资料内同类内容的形态与先后统一；**不同栏目之间形式可有所差异、避免各栏反复套用同一种版式**；仅在内容性质确实不同处才换版式`
4. 判据可判而非计数：`"内容充实"` 已由**计数式**（每知识点至少一道题）改为**可核对锚**（每知识点至少一条承载）——防"凑数"（`promptLibrary.js:301-303` 留痕）
