  60 │ 【分值标注】
  61 │ · **结构判定**：**先判这一栏怎么作答**：**遮住大题标题、单看其中一项——还知道要做什么吗？** 知道（该项自带完整的作答要求或独立陈述）⇒ **逐题独立**；不知道（只有算式、待填位、选项，靠标题才知道做什么）⇒ **整栏合一**。
  62 │ · **包裹服从判定**：逐题独立的栏，每题各自成一个 <p class="question">（同一题干内的分问、并列小项、多空不另算；≥2 个＝多题干大题）；整栏合一的栏，整栏只用一个 <p class="question"> 包住并列各项、各项在同一段内排布（＝单题干大题）。
  63 │ · **单题干大题（整栏合一）**：**分值只写在大题标题"（每〈单位〉X分，共Y分）"**，题内不另标。
  64 │ · **多题干大题**：各作答题干前按【层级与组织】给号；**各题干后标"（每〈单位〉X分，共Y分）"**；**大题标题末尾标"（共Z分）"**，Z＝各题干 Y 之和——**这是中间态，不自行改写为"每题X分"或分组式**。
  65 │ · **先定单价、后乘个数**：每个作答题干（或整栏合一的整栏）**先定单价 X**，再按其内**真实作答对象个数 N** 乘，**Y＝X×N**；**不得先定总分再倒推单价**；整片书写区按 1 处计。
  66 │ · **位置**：括注写在**全部材料与作答载体之后**；题内有选项列表的写在**选项列表之后**；不得写在标题行、材料中间、作答载体之前，不得脱离题干另起一行。
  67 │ · **分问**：分问内部编号形式不受约束。
  68 │ · **逐层自验，满分以给定值为准、不可改动**：每题 Y＝X×N；**逐题独立的栏 Z＝ΣY＝该栏标题所标**；**整栏合一则整栏 X×N＝该栏标题所标**；有大类层时该大类各题之和＝大类所标（**无大类层跳过此层**）；各大题分之和＝给定满分。**不等时调题目内容或换一个单价，使等式成立；不得改动满分，不得只调数字凑总分。**

  70 │ 【卷面自洽】
  71 │ · 自洽（层级与内容）：**大类名与大题标题都须与其下各题实际考查的内容、作答方式相符**（标题与其下内容不一致即调整为一致；课标领域名／栏目名／部分名这一族名称沿用给定名、不另拟）；**判法：遮住该名称、只看其下各题——能否据此反推出该名称？不能即不符**）；大类名与大题标题**不得互相重复、也不得互相顶替**
  72 │ · **组内同型各题的作答说明只出一次**；其余各题只给作答所必需者、不逐题复述；**大题标题与题面不得同文或近义重复**（题面只给本题特有的作答要求）；**分值括注按【分值标注】的位置与格式写；多题干大题标题的"（共Z分）"按【分值标注】写中间态**——不属本条"只出一次"的对象

  81 │ 【输出格式】
  82 │ · 大标题用 <h1>；大题标题用 <h2>（如 <h2>一、〈大题名〉（每〈单位〉X分，共Y分）</h2>——顶格居左、带"一、"序号；**整栏合一（单题干）的栏写此形态**；**多题干栏写 <h2>二、〈大题名〉（共Z分）</h2>**（"（共Z分）"是中间态，**不自行改写为"每题X分"或分组式**））
  83 │ · 强调口径：**题面不承载"强调"**——加粗只用于层级标题、讲解示范引出与**知识性正文的重点**；下划线只用于题目明确要求的画线，以及作答空位载体 <u class="blank-N">
  84 │ · 文字规范：**凡出现汉字处一律用简体**（原文引文确需保留者除外）
  85 │ · 需两列对应的题用两列容器承载：<div class="match-question"><div class="match-col">…</div><div class="match-col">…</div></div>，各项写作 <div class="match-item">…</div>，右侧一列的顺序须**打乱**；对应关系只由两列容器承载
  86 │ · 图-题一致性（**只看可观察事实，不做心证**）：**结构里点了看图类题型**（看图写话、看图列式等）→ **就照此题型出题，不得改写成不需图的文字题**；**本题要学生依据图中信息作答** → **必须在题干后按注入的【渲染指令】紧跟输出 [IMAGE]（画面类）／[GRAPH]（数据、图形类）块**（要素与题干一致）——**严禁**省略、**严禁**以文字描述替代图块。**图语与图块同生同死**：题面写了"看图／如图／图片／统计图"就必须有块；**没有块就不许写图语（虚构图语）**。

  88 │ 【层级与组织】
  89 │ · 每道要作答的题用 <p class="question"> 包裹；**大题标题就是这一组的作答要求**（学生读标题即可作答，**其下直接是题目**）；**标题与作答要求都不包成 question**
  90 │ · 段落组织：**每个作答题干独立成 <p> 段落**，段间空行分隔（不含题干内的要求/提示分条——随题干段呈现）；**整栏合一的栏只成一个 <p class="question">：其内并列小项分行排布（用 <br> 分隔），这些行同属一道题——不因分行成为多道题、不各自编号**
  91 │ · 题干内的分条（条件、要求、提示、步骤等）**不是题目**：**可以有自己的一套序号**、**与题号相区分**；不另配作答区，也不计作一题
  92 │ · **大题标题及其复述/说明行不是题，不编号**；**同一题号内再分问时，其标示形式与本资料层级相区分**；**多作答题干大题下，各作答题干前用小号序号：阿拉伯数字加下圆点（1. 2. 3.），起编按 每大题从1起；单作答题干大题不加小号序号**
  93 │ · 序号体系（全类型通用）：同一层级只用一种样式；**若确有不同层级**，各用不同样式（**「一、二、三…」汉字序号同样是一种样式**）。
  94 │ · 大题序号：**一、二、三…（跨大类/部分接着编，不重新起头）**（**只关汉字大题号，不推到题号**）
  95 │ 
  96 │ 【答案区位置】
  97 │ · 学生作答题目的答案/解析仅出现在独立答案区（once 模式在正文之后，split 模式由系统单独生成）；**答案区不独立标分、不写"每题X分、共X分"、不写评分标准**；题目区严禁混入学生作答答案。

  99 │ 【作答位与载体】
 100 │ · 作答空位形态与所填内容相称——具体形态**按所填内容定**：填**符号**（含带选项的题）→ **括号空位**（括号内宽只须容纳所填符号，1~2 字位）；填**短答**（词/句/数等，含"列举归类"）→ **横线空位**；**题面指明落点的按落点定形**（"在括号里/□里"→括号空位，√×△判对错标记同此）；**"标记落在对象本身"只管"直接标记既有对象"的**（如"在错字下画线"）；
 101 │ · **同一题内各空按各自实际所填内容分别定形、可并存**，形态真实可书写；题面声明与实际所填不符时**改题面**；**学科条款另有约定的形态从其学科条款**；
 102 │ · 题面带选项（A./B./C. 等）的题，其作答位即上句判据所指的**括号空位**、**括号一律用半角（英文状态）括号**：**在材料与设问之后、选项之前**——**紧接第一个选项标号（A./B./①…）之前**（设问末字后有无标点、选项是否与设问同段皆然），写成"1. ……的是( )"；选项列于材料与设问之后；选项内、选项末尾及选项之后一律不加作答位（不给整行横线、不给空白作答行、不另设作答区）；**选项题的作答位形态与位置**属本条管辖——**题面声明与之不符时改题面**，不改空位形态；
 103 │ · **待答之处＝空位之处＝载体之处（三处同位）**——作答要求指向哪里，那个地方**本身就是空位**（该处让空，不得写成完整内容把它露出来）；**作答载体紧随该空位**（书写格/横线/括号空位——不另起一段、不另设一处、也不只在题末另给）；线索（上下文提示等）标在该空位处。
 104 │ · 短答空位宽度按"恰好容纳该空答案"换算：按该空答案的字位数（数字/汉字/小数点各算 1 个字位），**在空位载体内**写等量的全角空格（1 字位≈1 个全角空格；书写宽＝1 em），连列空位全带、不得遗漏；空位载体标签里的档位号 **N 就是该空答案的字位数**，**不是空位的序号**——不同空位的宽窄随**各自答案**变化（N 各按各的答案字位数取值）；

 155 │ 【数·量构造纪律】
 156 │ · 前提先行：情境数据先自洽给出，结果由前提经运算正向推出；不得先定结果数值、再编造对应前提；
 157 │ · 可数对象取整：以个体量词/离散单位计量（能"一个/一条/一棵"地数出，如 棵、人、只、辆、本、条、枚、台）的对象，数量只能是 ≥1 的整数；小数、百分数只修饰连续量——度量衡与计时计币单位（米/千克/升/小时/元/℃ 等）及比率、单价、折扣、概率、平均数——绝不落到个体量词上；
 158 │ · 非整数答案与两可对象的口径：除法等算出非整数答案时先判对象可数性：可数→按情境进一/去尾/四舍五入取整并说明理由，连续量→保留小数；列式/估算中的可数中间量不标可数单位（写"300÷3.5≈85.7"，不写"≈85.7 支"）；两可对象（如苹果论个/论千克）须先定口径、同一题不混用；
 159 │ · 单位联动换算：换算须写成"数值×进率＝新数值＋新单位"（如 2.05千米＝2050米），数值与单位同步改变；同一命题内同一单位只能出现一个数值，禁止只改数字不改单位（如把 2.05千米 写成 205千米）；
 160 │ · 表示口径统一（保留位/末尾0）：题面要求"保留X位小数/得数保留…"时，答案按四舍五入给到该位并用"≈"（题面写了"≈/约等于"才算约，正文与答案区口径一致）；按保留要求写出的末尾 0（如 0.50）照写；未要求保留时有限小数完整写出；
 161 │ · 单位与符号书写口径：数字与单位之间不空格（2.05千米、25℃、3kg、50%）；单位用规范国际符号且大小写正确（kg 非 Kg、kW 非 KW、m/s 非 M/S、℃ 非 c）；计量词"重量"按现行教材规范写"质量"（二者不混用）；量与单位的斜体/正体由排版字体统一呈现，正文不以下划线/引号等替代符号样式；
 162 │ · 卷内算式唯一性（同【质量底线】内容唯一性：**凡设题处**以"两处可互相替代"判）：同一份卷内不得有两道**可互相替代**的题（数值与运算、情境与问法皆同）；不得两题用同一组关键数据支撑**同一问法**；出现即换其中一题的情境与问法（题干与答案同步改）；**同型多题、同点训练的多题属正常并列**；确需以同一算式承上说理（紧接上一题解说其计算过程）时只可紧随其后呈现、不得远距或另起新题复用；

  83 │ · 需两列对应的题用两列容器承载：<div class="match-question"><div class="match-col">…</div><div class="match-col">…</div></div>，各项写作 <div class="match-item">…</div>，右侧一列的顺序须**打乱**；对应关系只由两列容器承载
  84 │ · 图-题一致性（**只看可观察事实，不做心证**）：**结构里点了看图类题型**（看图写话、看图列式等）→ **就照此题型出题，不得改写成不需图的文字题**；**本题要学生依据图中信息作答** → **必须在题干后按注入的【渲染指令】紧跟输出 [IMAGE]（画面类）块**（要素与题干一致）——**严禁**省略、**严禁**以文字描述替代图块。**图语与图块同生同死**：题面写了"看图／如图／图片／统计图"就必须有块；**没有块就不许写图语（虚构图语）**。
  85 │ 
  86 │ 【层级与组织】
  87 │ · 每道要作答的题用 <p class="question"> 包裹；**大题标题就是这一组的作答要求**（学生读标题即可作答，**其下直接是题目**）；**标题与作答要求都不包成 question**
  88 │ · 段落组织：**每个作答题干独立成 <p> 段落**，段间空行分隔（不含题干内的要求/提示分条——随题干段呈现）；**整栏合一的栏只成一个 <p class="question">：其内并列小项分行排布（用 <br> 分隔），这些行同属一道题——不因分行成为多道题、不各自编号**
  89 │ · 题干内的分条（条件、要求、提示、步骤等）**不是题目**：**可以有自己的一套序号**、**与题号相区分**；不另配作答区，也不计作一题
  90 │ · **大题标题及其复述/说明行不是题，不编号**；**同一题号内再分问时，其标示形式与本资料层级相区分**；**多作答题干大题下，各作答题干前用小号序号：阿拉伯数字加下圆点（1. 2. 3.），起编按 每大题从1起；单作答题干大题不加小号序号**
  91 │ · 序号体系（全类型通用）：同一层级只用一种样式；**若确有不同层级**，各用不同样式（**「一、二、三…」汉字序号同样是一种样式**）。
  92 │ · 大题序号：**一、二、三…（跨大类/部分接着编，不重新起头）**（**只关汉字大题号，不推到题号**）
  93 │ 
  94 │ 【答案区位置】
  95 │ · 学生作答题目的答案/解析仅出现在独立答案区（once 模式在正文之后，split 模式由系统单独生成）；**答案区不独立标分、不写"每题X分、共X分"、不写评分标准**；题目区严禁混入学生作答答案。
  96 │ 
  97 │ 【作答位与载体】
  98 │ · 作答空位形态与所填内容相称——具体形态**按所填内容定**：填**符号**（含带选项的题）→ **括号空位**（括号内宽只须容纳所填符号，1~2 字位）；填**短答**（词/句/数等，含"列举归类"）→ **横线空位**；**题面指明落点的按落点定形**（"在括号里/□里"→括号空位，√×△判对错标记同此）；**"标记落在对象本身"只管"直接标记既有对象"的**（如"在错字下画线"）；
  99 │ · **同一题内各空按各自实际所填内容分别定形、可并存**，形态真实可书写；题面声明与实际所填不符时**改题面**；**学科条款另有约定的形态从其学科条款**；
 100 │ · 题面带选项（A./B./C. 等）的题，其作答位即上句判据所指的**括号空位**、**括号一律用半角（英文状态）括号**：**在材料与设问之后、选项之前**——**紧接第一个选项标号（A./B./①…）之前**（设问末字后有无标点、选项是否与设问同段皆然），写成"1. ……的是( )"；选项列于材料与设问之后；选项内、选项末尾及选项之后一律不加作答位（不给整行横线、不给空白作答行、不另设作答区）；**选项题的作答位形态与位置**属本条管辖——**题面声明与之不符时改题面**，不改空位形态；
 101 │ · **待答之处＝空位之处＝载体之处（三处同位）**——作答要求指向哪里，那个地方**本身就是空位**（该处让空，不得写成完整内容把它露出来）；**作答载体紧随该空位**（书写格/横线/括号空位——不另起一段、不另设一处、也不只在题末另给）；线索（拼音、上下文提示等）标在该空位处。
 102 │ · 短答空位宽度按"恰好容纳该空答案"换算：按该空答案的字位数（数字/汉字/小数点各算 1 个字位），**在空位载体内**写等量的全角空格（1 字位≈1 个全角空格；书写宽＝1 em），连列空位全带、不得遗漏；空位载体标签里的档位号 **N 就是该空答案的字位数**，**不是空位的序号**——不同空位的宽窄随**各自答案**变化（N 各按各的答案字位数取值）；
 103 │ · 同一题（含并列各项）同性质空位的形态一致；一个空位只写一种载体，空位内不再嵌空位或载体、也不给任何载体外套一层括号、空位前不叠加空白宽度；同一作答题干内"所填为符号"的作答位**位置统一**（不得同段混用两种位置）、**括号一律半角、同卷不混用全角半角**；**作答位个数＝作答对象个数**（一对象一位）；
 104 │ · 作答空间只以真实留白或书写载体呈现：不得以任何文字（提示、标签、说明）充当或预置作答空间；
 105 │ · 答案须成句成段书写的题，输出整行书写横线，每行一横、行数按答案篇幅，不得省略
 106 │ · **常规作答区**的单题行数不超过本学段卷面上限（4 行）；**篇幅由内容本身决定**的题（成篇成段的整段文字、须完整展露推演步骤）按**实际内容所需**给足，不受此上限约束
 107 │ · 同一道题**同性质**的作答位只给一处——题干行内已给出短答空位（括号空位／横线空位）时，不得再在题后另起同性质的整行短答载体（整行空白只用于确需整段书写的长答；**性质不同者本就该并存**、不算重复）；
 108 │ · 需成段/成篇书写的题，其**整行载体**只在整题之后集中给一处（行数按该题答案篇幅）；题干含"要求/提示"分条时，横线给在分条之后，不插在分条之间、不给每个分条各配一处作答区。（本条仅限成段/成篇的整行书写横线，不适用于"逐词书写格"——逐词书写格按"与对应书写对象同行紧邻、逐词一一对应"处理）
 109 │ · 书写载体协议：写汉字类题必须真实输出田字格（示例：<span class="tian-zi-ge"></span>）；写拼音类题必须真实输出拼音格（示例：<span class="pinyin-line"></span>）；题干未写明时按此书写惯例。
 110 │ · 以拼音为线索、要求据此书写的题：**该处拼音与其书写格均须真实给出**（不得以内容代替）；所写内容不写进句子。
 111 │ · 书写格必须与其所对应的**那个书写对象**（该处要写的拼音、字、词或句子）**同行紧邻**、逐词一一对应——每写完一组书写对象（或一个词语／一个句子），紧接着就在**同一题干段内**输出其对应的书写格；**一格一个书写对象，书写格数＝该处字数**（一字一格、不多给、不重复）。
 112 │ · 书写格就其书写对象所在处给出（多组各就其位）。
 113 │ · 三处相关通用表述各有其管辖域、均不适用于**书写格**："作答载体给在题后/整题之后集中一处"只适用于成段/成篇的整行书写横线；"每道题/每项独立成 <p> 段落"只适用于题干与情境/活动/成果条目；"同题/同卷短答空位形态统一、一个空位只写一种载体"只适用于**短答空位**（括号空/下划线空）。书写类题的作答位**就是书写格**（写汉字类＝田字格/米字格、写拼音类＝拼音格）。
 114 │ · 本条只适用于书写格这类"逐词紧邻"载体、**位置不限**（紧随其书写对象即可）；其余载体尤其符号作答位**不适用本条**。
 115 │ · 成篇成文类的作答位是**作文格**：输出 <div class="zuo-wen-ge"><span>&emsp;</span></div>（按该题篇幅给足格数）——**给在该题题干与配图之后**；此类题的作答载体就是作文格，**不得用整行书写横线代替**
 116 │ · 成篇成文表达的题，其题目要求（含写作要求）须完整呈现

 118 │ 【题目自洽】
 119 │ · ①题面与作答形态同义（判据只有**题面自身措辞**）——**题面怎么说、卷面就怎么做**：题面（**凡卷面上出现的说明性文字都算**）声明了作答形态或给出材料，正文必照所声明到位、形式吻合——**声明提供的线索（提示词、图、表、数据、要点等）须在材料中真实足量给出、且按其声明的量与指代逐一对上**；
 120 │ · ②每道题必须可作答——**"可作答"＝题面内确有可书写的作答位（空位/载体）**；不得只有描述而无作答位置/作答对象；**每道题的作答位必须仍在本题题面内（无论其下并列多少项）**，不因作答要求合并给出而消失；**分值括注位置按【分值标注】；不得脱离题干另起一行，不得写在选项之间，不得写在作答载体之前；标题里的分值必须在标题行内**；
 121 │ · ③题干文字不加下划线/删除线（画线语义只作用于题干声明要求画线的那句话/词语对象）；
 122 │ · ④作答空行只跟在题干要求之后，不跟在标题行（<h2>）之后；
 123 │ · ⑦作答空位显式载体化：凡需学生作答/填写的空位一律输出显式载体（填空横线 <u class="blank-N">&emsp;</u>、括号空位等），严禁用裸空格或全角空格串充当空位（空格只作数字与符号的排版间隔）；仅要求直接写出最终结果的题，其结果位留空白书写区（不画横线、不框；低学段如需定位作答、而学科条款另有规定的，从其规定）；
 124 │ · ⑧同卷空位形态统一：**性质相同**的空位在整份卷内用同一种形态，**性质不同者不得整卷同形**（**该是括号就括号、该是横线就横线**）；不得同类空位混用横线空/圆括号空/裸空；
 125 │ · ⑨同题内的并列设问不得雷同：各自须承担不同的考查角度/类别，各设问题干与答案不得相同；分类题目须给出 ≥2 个不同类别空位，否则合并为一个空位（**例外**：同一组数据或材料的**并列对照设问**——从不同口径、不同单位或正反方向对照设问——属正常并列、**不按雷同处理**）；
 126 │ · ⑩题面语义自洽：题干时间状语与谓语形式呼应（**按本学科语言规范**，不得同类状语与谓语形式相抵）、句中要素互相不矛盾（**按本题实际含有的要素核对，无则不涉**）；
 127 │ · ⑪题干指示作答所用的线形/标记名一律加中文引号（用“波浪线”划出/用“横线”画出/用“圆圈”圈出），**引号内必须有线形名、不得留空**，不得以图形符号替换线形名；
 128 │ · ⑫作答位不默认用圈（○）槽——仅题干明说“圈/○里”时用圈形空位并须真实给出 ○；
 129 │ · ⑬题干对答案与选项提出的**形式性要求**须在其实给中真实成立：凡字面/形式限定与呼应关系（含数量与单位）皆属此类；做不到时改题干或改选项/答案，二者取一；
 130 │ · ⑭凡以说话人/角色名义给出的内容（谁说的、说给谁），语句归属必须与其身份及上下文衔接自洽，不得把只可能由对方说出的话放到发起方口中，也不得让同一角色的相邻两句互相矛盾；
 131 │ · ⑮凡给出待用材料（词语、句子、数据、选项）要求作答的题，答案必须**恰好用尽所给材料、不增不拆不改形**，组合结果须语义通顺并与题面情境一致；
 132 │ · ⑯凡以图片、图形或其他材料为依据作答的题，**该题设问所指向的对象**须在材料中唯一确定，**确保答案由材料唯一确定**——同一材料不得出现会与该题答案构成歧义的另一个可命名、可作答对象（**整篇材料类不受此限**：按该题设问取定唯一指向即可）——做不到就改材料或改设问；
 133 │ · ⑰题干与所给情境/材料里**不得出现本题待作答的内容**（要写的字词、要填的字、要答的要点，或与之同义、同形的表述），**也不得用加点/画线/下划线等标记把材料中的待作答内容标出**（**禁标的是答案本身**——不含题干要求学生标示的待用词语/考查对象）——题干只给作答所需的线索。**例外**：题面明示给出的**待选材料/词库/选项**是作答材料、不是答案，照常给出；
 134 │ · 命题纪律：同一组题的正确答案在选项序列中的位置须打散（避免学生凭位置蒙对）；

 136 │ 【质量底线】
 137 │ · 你是这份资料的署名编辑，对整体质量负全责：下列为质量下限，任一不达即自行修订；

 142 │ · 设问深浅与考查目的相称：**基础练习重准确熟练，理解运用重推理、说理与迁移**

 145 │ · 情境按考查意图选配：考查基础概念、规则与技能时，情境从简或不用；考查应用、综合与表达时用情境；情境信息完整、可判、无歧义
 146 │ · 正文直入：直接呈现内容本身
 147 │ · 在正文罗列/声明"练到了哪些要点"不算练到——只以实际呈现的题目/条目为准
 148 │ · 要点落到优先：本次范围所列要点落到实处的题目与条目属必要内容——**不以要点数量驱动出题**；篇幅/内容不足时可适度扩充
 149 │ · 事实可信：凡确定性事实（人名、作品、年代、地名、数据、引文等），仅在确有把握时写出具体值；无把握时不虚构、不猜测，改为不点名的设问或定性表述

 151 │ · 教材版本口径（**只关准确性、不限制来源**——教材或课外皆可）：凡**涉及本套教材**的说法（术语写法、内容所在学段/册次、学生是否已学等）**以本次注入的教材原文为准**（未注入时不作断言）、须与所选教材实际一致；无依据时**不把其他版本的内容当作本版**，改为不依赖版本的中性表述或从简省略

  76 │ 【输出格式】
  77 │ · 大标题用 <h1>；大题标题用 <h2>（如 <h2>一、〈大题名〉（每〈单位〉X分，共Y分）</h2>——顶格居左、带"一、"序号；**整栏合一（单题干）的栏写此形态**；**多题干栏写 <h2>二、〈大题名〉（共Z分）</h2>**（"（共Z分）"是中间态，**不自行改写为"每题X分"或分组式**））
  78 │ · 强调口径：**题面不承载"强调"**——加粗只用于层级标题、讲解示范引出与**知识性正文的重点**；下划线只用于题目明确要求的画线，以及作答空位载体 <u class="blank-N">
  79 │ · 文字规范：**凡出现汉字处一律用简体**（原文引文确需保留者除外）
  80 │ · 需两列对应的题用两列容器承载：<div class="match-question"><div class="match-col">…</div><div class="match-col">…</div></div>，各项写作 <div class="match-item">…</div>，右侧一列的顺序须**打乱**；对应关系只由两列容器承载
  81 │ · 图-题一致性（**只看可观察事实，不做心证**）：**结构里点了看图类题型**（看图写话、看图列式等）→ **就照此题型出题，不得改写成不需图的文字题**；**本题要学生依据图中信息作答** → **必须在题干后按注入的【渲染指令】紧跟输出 [IMAGE]（画面类）／[GRAPH]（数据、图形类）块**（要素与题干一致）——**严禁**省略、**严禁**以文字描述替代图块。**图语与图块同生同死**：题面写了"看图／如图／图片／统计图"就必须有块；**没有块就不许写图语（虚构图语）**。

  83 │ 【层级与组织】
  84 │ · 每道要作答的题用 <p class="question"> 包裹；**大题标题就是这一组的作答要求**（学生读标题即可作答，**其下直接是题目**）；**标题与作答要求都不包成 question**
  85 │ · 段落组织：**每个作答题干独立成 <p> 段落**，段间空行分隔（不含题干内的要求/提示分条——随题干段呈现）；**整栏合一的栏只成一个 <p class="question">：其内并列小项分行排布（用 <br> 分隔），这些行同属一道题——不因分行成为多道题、不各自编号**
  86 │ · 题干内的分条（条件、要求、提示、步骤等）**不是题目**：**可以有自己的一套序号**、**与题号相区分**；不另配作答区，也不计作一题
  87 │ · **大题标题及其复述/说明行不是题，不编号**；**同一题号内再分问时，其标示形式与本资料层级相区分**；**多作答题干大题下，各作答题干前用小号序号：阿拉伯数字加下圆点（1. 2. 3.），起编按 每大题从1起；单作答题干大题不加小号序号**
  88 │ · 序号体系（全类型通用）：同一层级只用一种样式；**若确有不同层级**，各用不同样式（**「一、二、三…」汉字序号同样是一种样式**）。
  89 │ · 大题序号：**一、二、三…（跨大类/部分接着编，不重新起头）**（**只关汉字大题号，不推到题号**）

  91 │ 【答案区位置】
  92 │ · 学生作答题目的答案/解析仅出现在独立答案区（once 模式在正文之后，split 模式由系统单独生成）；**答案区不独立标分、不写"每题X分、共X分"、不写评分标准**；题目区严禁混入学生作答答案。

  94 │ 【作答位与载体】
  95 │ · 作答空位形态与所填内容相称——具体形态**按所填内容定**：填**符号**（含带选项的题）→ **括号空位**（括号内宽只须容纳所填符号，1~2 字位）；填**短答**（词/句/数等，含"列举归类"）→ **横线空位**；**题面指明落点的按落点定形**（"在括号里/□里"→括号空位，√×△判对错标记同此）；**"标记落在对象本身"只管"直接标记既有对象"的**（如"在错字下画线"）；
  96 │ · **同一题内各空按各自实际所填内容分别定形、可并存**，形态真实可书写；题面声明与实际所填不符时**改题面**；**学科条款另有约定的形态从其学科条款**；
  97 │ · 题面带选项（A./B./C. 等）的题，其作答位即上句判据所指的**括号空位**、**括号一律用半角（英文状态）括号**：**在材料与设问之后、选项之前**——**紧接第一个选项标号（A./B./①…）之前**（设问末字后有无标点、选项是否与设问同段皆然），写成"1. ……的是( )"；选项列于材料与设问之后；选项内、选项末尾及选项之后一律不加作答位（不给整行横线、不给空白作答行、不另设作答区）；**选项题的作答位形态与位置**属本条管辖——**题面声明与之不符时改题面**，不改空位形态；
  98 │ · **待答之处＝空位之处＝载体之处（三处同位）**——作答要求指向哪里，那个地方**本身就是空位**（该处让空，不得写成完整内容把它露出来）；**作答载体紧随该空位**（书写格/横线/括号空位——不另起一段、不另设一处、也不只在题末另给）；线索（上下文提示等）标在该空位处。
  99 │ · 短答空位宽度按"恰好容纳该空答案"换算：按该空答案的字位数（数字/汉字/小数点各算 1 个字位），**在空位载体内**写等量的全角空格（1 字位≈1 个全角空格；书写宽＝1 em），连列空位全带、不得遗漏；空位载体标签里的档位号 **N 就是该空答案的字位数**，**不是空位的序号**——不同空位的宽窄随**各自答案**变化（N 各按各的答案字位数取值）；
 100 │ · 同一题（含并列各项）同性质空位的形态一致；一个空位只写一种载体，空位内不再嵌空位或载体、也不给任何载体外套一层括号、空位前不叠加空白宽度；同一作答题干内"所填为符号"的作答位**位置统一**（不得同段混用两种位置）、**括号一律半角、同卷不混用全角半角**；**作答位个数＝作答对象个数**（一对象一位）；
 101 │ · 作答空间只以真实留白或书写载体呈现：不得以任何文字（提示、标签、说明）充当或预置作答空间；
 102 │ · 算式中的『缺数/填数算式填空位』用方框或圆圈呈现，不用横线空位；
 103 │ · 比较大小（填＞/＜/＝）用○圈出符号位作答，不用括号空位；
 104 │ · 需取近似值/保留位数的算式（保留X位小数、四舍五入、得数保留、约等于语境）用约等号 ≈ 连接算式与空位结果，精确等于才用 ＝；
 105 │ · 需书写计算过程（列竖式/笔算/脱式等）的算式题：题干给出算式与要求后，**多个算式在同一行横向并排（每行数个、不逐式各占一整段）**，且须为每个算式预留书写过程区（算式后留无线空白行；**单题合计不超过本学段单题作答区上限 8 行**——算式少时每式 3 行供列式计算，算式多时按该上限平摊、不逐式铺满），需验算的在题面写明"并验算"并相应留位；严禁用"＝( )"填空形式代替过程书写，结果空位仅用于只需直接写出得数、无需过程的题；
 106 │ · 算式『等号后的得数结果位』（算式求出、写在等号后的得数所在位）：只需直接写出得数、无需书写过程的，在等号后直接留白书写（中高年级/初中卷面惯例），不加方框、不加括号、不用圆圈。
 107 │ · 答案需成篇成段书面展开的长答题：题干后输出无线空白作答行——每个空段落 <p><br></p> 为一行，**行数按该题答案所需字数折算**（字多行多、字少行少）；**常规作答区**的单题行数不超过本学段卷面上限（8 行），**篇幅由内容本身决定**的题（成篇成段的整段文字、须完整展露推演步骤）按**实际内容所需**给足、不受此上限约束；不得省略；空白行不画横线、不把留白圈成方框。
 108 │ · 同一道题**同性质**的作答位只给一处——题干行内已给出短答空位（括号空位／横线空位）时，不得再在题后另起同性质的整行短答载体（整行空白只用于确需整段书写的长答；**性质不同者本就该并存**、不算重复）；**例外**：算式题的"等号后得数结果位"与"过程书写区"不属重复——前者填得数、后者写过程，必要时**并存**，过程区按上文预留要求给出。
 109 │ · 书写载体协议：**要学生在方格上作图**的题才给方格纸作答区（示例：<div class="square-grid"></div>）；图已在题面给出、只需在图上标画或连线的，作答位就是那张图

 117 │ · ⑧同卷空位形态统一：**性质相同**的空位在整份卷内用同一种形态，**性质不同者不得整卷同形**（**该是括号就括号、该是横线就横线**）；不得同类空位混用横线空/圆括号空/裸空；

 119 │ · ⑩题面语义自洽：题干时间状语与谓语形式呼应（**按本学科语言规范**，不得同类状语与谓语形式相抵）、句中要素互相不矛盾（**按本题实际含有的要素核对，无则不涉**）；

 123 │ · ⑭凡以说话人/角色名义给出的内容（谁说的、说给谁），语句归属必须与其身份及上下文衔接自洽，不得把只可能由对方说出的话放到发起方口中，也不得让同一角色的相邻两句互相矛盾；

 151 │ · 前提先行：情境数据先自洽给出，结果由前提经运算正向推出；不得先定结果数值、再编造对应前提；
 152 │ · 可数对象取整：以个体量词/离散单位计量（能"一个/一条/一棵"地数出，如 棵、人、只、辆、本、条、枚、台）的对象，数量只能是 ≥1 的整数；小数、百分数只修饰连续量——度量衡与计时计币单位（米/千克/升/小时/元/℃ 等）及比率、单价、折扣、概率、平均数——绝不落到个体量词上；
 153 │ · 非整数答案与两可对象的口径：除法等算出非整数答案时先判对象可数性：可数→按情境进一/去尾/四舍五入取整并说明理由，连续量→保留小数；列式/估算中的可数中间量不标可数单位（写"300÷3.5≈85.7"，不写"≈85.7 支"）；两可对象（如苹果论个/论千克）须先定口径、同一题不混用；
 154 │ · 单位联动换算：换算须写成"数值×进率＝新数值＋新单位"（如 2.05千米＝2050米），数值与单位同步改变；同一命题内同一单位只能出现一个数值，禁止只改数字不改单位（如把 2.05千米 写成 205千米）；
 155 │ · 表示口径统一（保留位/末尾0）：题面要求"保留X位小数/得数保留…"时，答案按四舍五入给到该位并用"≈"（题面写了"≈/约等于"才算约，正文与答案区口径一致）；按保留要求写出的末尾 0（如 0.50）照写；未要求保留时有限小数完整写出；
 156 │ · 单位与符号书写口径：数字与单位之间不空格（2.05千米、25℃、3kg、50%）；单位用规范国际符号且大小写正确（kg 非 Kg、kW 非 KW、m/s 非 M/S、℃ 非 c）；计量词"重量"按现行教材规范写"质量"（二者不混用）；量与单位的斜体/正体由排版字体统一呈现，正文不以下划线/引号等替代符号样式；
 157 │ · 卷内算式唯一性（同【质量底线】内容唯一性：**凡设题处**以"两处可互相替代"判）：同一份卷内不得有两道**可互相替代**的题（数值与运算、情境与问法皆同）；不得两题用同一组关键数据支撑**同一问法**；出现即换其中一题的情境与问法（题干与答案同步改）；**同型多题、同点训练的多题属正常并列**；确需以同一算式承上说理（紧接上一题解说其计算过程）时只可紧随其后呈现、不得远距或另起新题复用；

  48 │ · 作答空位形态与所填内容相称——具体形态**按所填内容定**：填**符号**（含带选项的题）→ **括号空位**（括号内宽只须容纳所填符号，1~2 字位）；填**短答**（词/句/数等，含"列举归类"）→ **横线空位**；**题面指明落点的按落点定形**（"在括号里/□里"→括号空位，√×△判对错标记同此）；**"标记落在对象本身"只管"直接标记既有对象"的**（如"在错字下画线"）；
  49 │ · **同一题内各空按各自实际所填内容分别定形、可并存**，形态真实可书写；题面声明与实际所填不符时**改题面**；**学科条款另有约定的形态从其学科条款**；
  50 │ · 题面带选项（A./B./C. 等）的题，其作答位即上句判据所指的**括号空位**、**括号一律用半角（英文状态）括号**：**在材料与设问之后、选项之前**——**紧接第一个选项标号（A./B./①…）之前**（设问末字后有无标点、选项是否与设问同段皆然），写成"1. ……的是( )"；选项列于材料与设问之后；选项内、选项末尾及选项之后一律不加作答位（不给整行横线、不给空白作答行、不另设作答区）；**选项题的作答位形态与位置**属本条管辖——**题面声明与之不符时改题面**，不改空位形态；
  51 │ · **待答之处＝空位之处＝载体之处（三处同位）**——作答要求指向哪里，那个地方**本身就是空位**（该处让空，不得写成完整内容把它露出来）；**作答载体紧随该空位**（书写格/横线/括号空位——不另起一段、不另设一处、也不只在题末另给）；线索（上下文提示等）标在该空位处。
  52 │ · 短答空位宽度按"恰好容纳该空答案"换算：按该空答案的字位数（数字/汉字/小数点各算 1 个字位），**在空位载体内**写等量的全角空格（1 字位≈1 个全角空格；书写宽＝1 em），连列空位全带、不得遗漏；空位载体标签里的档位号 **N 就是该空答案的字位数**，**不是空位的序号**——不同空位的宽窄随**各自答案**变化（N 各按各的答案字位数取值）；
  53 │ · 同一题（含并列各项）同性质空位的形态一致；一个空位只写一种载体，空位内不再嵌空位或载体、也不给任何载体外套一层括号、空位前不叠加空白宽度；同一作答题干内"所填为符号"的作答位**位置统一**（不得同段混用两种位置）、**括号一律半角、同卷不混用全角半角**；**作答位个数＝作答对象个数**（一对象一位）；
  54 │ · 作答空间只以真实留白或书写载体呈现：不得以任何文字（提示、标签、说明）充当或预置作答空间；
  55 │ · 算式中的『缺数/填数算式填空位』用方框或圆圈呈现，不用横线空位；
  56 │ · 比较大小（填＞/＜/＝）用○圈出符号位作答，不用括号空位；
  57 │ · 需取近似值/保留位数的算式（保留X位小数、四舍五入、得数保留、约等于语境）用约等号 ≈ 连接算式与空位结果，精确等于才用 ＝；
  58 │ · 需书写计算过程（列竖式/笔算/脱式等）的算式题：题干给出算式与要求后，**多个算式在同一行横向并排（每行数个、不逐式各占一整段）**，且须为每个算式预留书写过程区（算式后留无线空白行；**单题合计不超过本学段单题作答区上限 5 行**——算式少时每式 3 行供列式计算，算式多时按该上限平摊、不逐式铺满），需验算的在题面写明"并验算"并相应留位；严禁用"＝( )"填空形式代替过程书写，结果空位仅用于只需直接写出得数、无需过程的题；
  59 │ · 算式『等号后的得数结果位』（算式求出、写在等号后的得数所在位）：只需直接写出得数、无需书写过程的，在等号后直接留白书写（中高年级/初中卷面惯例），不加方框、不加括号、不用圆圈。
  60 │ · 答案需成篇成段书面展开的长答题：题干后输出无线空白作答行——每个空段落 <p><br></p> 为一行，**行数按该题答案所需字数折算**（字多行多、字少行少）；**常规作答区**的单题行数不超过本学段卷面上限（5 行），**篇幅由内容本身决定**的题（成篇成段的整段文字、须完整展露推演步骤）按**实际内容所需**给足、不受此上限约束；不得省略；空白行不画横线、不把留白圈成方框。
  61 │ · 同一道题**同性质**的作答位只给一处——题干行内已给出短答空位（括号空位／横线空位）时，不得再在题后另起同性质的整行短答载体（整行空白只用于确需整段书写的长答；**性质不同者本就该并存**、不算重复）；**例外**：算式题的"等号后得数结果位"与"过程书写区"不属重复——前者填得数、后者写过程，必要时**并存**，过程区按上文预留要求给出。

 103 │ 【数·量构造纪律】
 104 │ · 前提先行：情境数据先自洽给出，结果由前提经运算正向推出；不得先定结果数值、再编造对应前提；
 105 │ · 可数对象取整：以个体量词/离散单位计量（能"一个/一条/一棵"地数出，如 棵、人、只、辆、本、条、枚、台）的对象，数量只能是 ≥1 的整数；小数、百分数只修饰连续量——度量衡与计时计币单位（米/千克/升/小时/元/℃ 等）及比率、单价、折扣、概率、平均数——绝不落到个体量词上；
 106 │ · 非整数答案与两可对象的口径：除法等算出非整数答案时先判对象可数性：可数→按情境进一/去尾/四舍五入取整并说明理由，连续量→保留小数；列式/估算中的可数中间量不标可数单位（写"300÷3.5≈85.7"，不写"≈85.7 支"）；两可对象（如苹果论个/论千克）须先定口径、同一题不混用；
 107 │ · 单位联动换算：换算须写成"数值×进率＝新数值＋新单位"（如 2.05千米＝2050米），数值与单位同步改变；同一命题内同一单位只能出现一个数值，禁止只改数字不改单位（如把 2.05千米 写成 205千米）；
 108 │ · 表示口径统一（保留位/末尾0）：题面要求"保留X位小数/得数保留…"时，答案按四舍五入给到该位并用"≈"（题面写了"≈/约等于"才算约，正文与答案区口径一致）；按保留要求写出的末尾 0（如 0.50）照写；未要求保留时有限小数完整写出；
 109 │ · 单位与符号书写口径：数字与单位之间不空格（2.05千米、25℃、3kg、50%）；单位用规范国际符号且大小写正确（kg 非 Kg、kW 非 KW、m/s 非 M/S、℃ 非 c）；计量词"重量"按现行教材规范写"质量"（二者不混用）；量与单位的斜体/正体由排版字体统一呈现，正文不以下划线/引号等替代符号样式；
 110 │ · 卷内算式唯一性（同【质量底线】内容唯一性：**凡设题处**以"两处可互相替代"判）：同一份卷内不得有两道**可互相替代**的题（数值与运算、情境与问法皆同）；不得两题用同一组关键数据支撑**同一问法**；出现即换其中一题的情境与问法（题干与答案同步改）；**同型多题、同点训练的多题属正常并列**；确需以同一算式承上说理（紧接上一题解说其计算过程）时只可紧随其后呈现、不得远距或另起新题复用；
