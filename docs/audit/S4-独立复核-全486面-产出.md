## 三、语义层专项（不可机检部分）

### ① 过严候选 / 机检盲区（**本轮最高价值发现**）

**F1｜T19·G9 清零（全量口径）是"零命中"锚＝空转**。该锚 `re=/本单元(?:(?!必记)[^，。；：]){0,20}内容都涉及到/g, expect:0`——在 **486 面上命中 0 次**，故**永不可能判红**。而语义等价的全量口径「〈X〉都涉及到」实际落在 **211 面**：

- `review-*`（54 面全含）：「知识框架——【要求·须逐项落实】本单元字词句段篇知识都涉及到」
- `summary-*`（54 面全含）：「…本单元概念、法则、公式、方法都涉及到，用结构图或网络图呈现…」

**判**：锚的**自述适用面**（"清零＝全量口径禁词·全域"）与**实覆盖**不符。若定位为**回归锁**（只防旧字面复活）⇒ 成立；若作为"全量口径已清零"的**判据** ⇒ **不成立**。这正是 §三·1 要我盯的"写窄/写死"的**形状**（一个词级例外 `(?!必记)` 恰使 49 面卷面句免检）。**须由我方提供源码依据**：该例外是为"教辅合法句误伤"而设，还是为"让门变绿"而设。

**F2｜"覆盖口径"指针在 483 面无显式定义（悬空指针）**。486 面均含「覆盖**到位、不偏侧**（**覆盖到什么程度按本资料的覆盖口径**）」；但显式给出"覆盖口径"定义的只有 **exam×语文 3 面**（"抽样命题，不要求全量"）。其余 483 面该指针对读者**不可就地解析**（须从【卷面结构】大题分值或【锚点清单】"本次范围"反推）。更关键：**exam×非语文 51 面既未声明"抽样"也未声明"全量"** ⇒ 其"覆盖到位、不偏侧"**缺可判法**，与 T20·③ 自定的"改可判关系"精神相抵。

**F3｜过严候选（1 处，附我方声明）**。`T16·题类不注入三域`（`expect: CONTENT.has(genType)?1:0`）——非内容型面读到的是**反向**要求（非 content 面**必须不出现**【尾约束·全文自洽】）；该锚以"全域恒 1/0"方式写死，语义上是"类型形态"约束而非"注不注入"的断言，命名与判据略脱节（建议改名为"类型形态·三域归属"）。**未发现**会造成生成侧"过度约束"的过严条（各面 ⑬ 带**"二者取一"**、⑯ 带**"做不到就改材料或改设问"**的**可回退口**，属促规范而非死约束）。
