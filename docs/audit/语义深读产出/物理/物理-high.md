   - review 栏：`复习目标 / 知识框架 / 核心知识梳理 / 典型题析 / 易错聚焦 / 综合自测`。
   两者同属「知识归纳型」（各自【素材使用约定】均写「本资料为知识归纳型」），栏目名一对一近义（知识框架↔知识框架、重点梳理↔核心知识梳理、典型例题↔典型题析、易错辨析↔易错聚焦）。**同片同科两类型仅差「复习目标／综合自测」**，存在串味/定位重叠风险（判定纪律要求给两句原文，已给）。
2. **命题/练习型（exam/practice/special/reading/errorbook）与知识归纳型（preview/summary/dictation/review）分界**：后者四份【素材使用约定】一律声明「正文以内容本身呈现」，但栏目又要求作答位（预习检测／典型例题／默写留空／综合自测）。**同一声明与「含题」栏目并存于四份**；其中 summary 用【创作要求】4 显式折衷（「载体只用于作答位…答案与解析不整块包进标记」），**dictation 无折衷条款 → 判相抵**（见 §二、§四）。
3. **组织风格单档分布**：practice/special/reading＝scenario_each，preview＝task_driven，summary＝mindmap，review＝framework；exam/dictation/errorbook＝不注入。属外部输入（豁免②），不计相抵；其中三处与通用条款的并存张力记「待裁」（practice/reading/summary）。
4. **【物理·高中要点】内容全片 9 份完全一致**：「受力分析、电路与光路作图规范；实验探究重原理与数据处理；运用物理规律解决问题过程完整、步骤严谨。」——对「高一」而言，「光路作图」属选择性必修课程（非高一必修范围），存在跨学段指向，见 §四、§五。

## 四、缺口清单

1. **exam｜卷面结构要求的考查范围与「高一」学段匹配存疑**
   - 描述：【卷面结构】四要求计算题含「电磁学综合」，但本片学段＝`high（高一）`；电磁学（必修三）通常非高一内容。
   - 应在何处：【卷面结构】计算题要求行与【学段特点】/【学业质量水平】处应显式限定本学段范围（或说明本单元范围）。
   - 证据：逐字——「【任务】生成正式考卷：物理**高一**（满分100分，时长75分钟）」↔「四、计算题｜分值 32分——【要求·须逐项落实】**力学综合与电磁学综合**，要求规范作答」。
2. **special｜「每栏含解析」与答案区条款相抵（真错，须改）**
   - 描述：创作要求命令「每栏含…解析」，答案区命令「非讲解示范栏目严禁输出解析」，二者不可同真。
   - 应在何处：【创作要求】细致与深度要求，或【答案区位置】/【输出约定】须改写其一以消歧。
   - 证据：逐字——「**每栏含易错点辨识与思路点拨**，解析讲明"错因—如何避免—正确思路"，不只给答案。」↔「**除讲解示范型栏目外**，本次只输出资料/试卷正文…**严禁在正文中输出任何答案、解析、评分标准**」。
3. **dictation｜「知识归纳型／正文以内容本身呈现」与「留空呈现」相抵（真错，须改）**
   - 描述：默写纸须留空待答，但声明却写「正文以内容本身呈现」（把内容完整露出）。
   - 应在何处：【素材使用约定】该类型应改声明为「命题/练习型」或增补「留空呈现」口径。
   - 证据：逐字——「本资料为知识归纳型：…**正文以内容本身呈现**（不加出处标注与溯源字样）。」↔「本单元要求掌握的概念、规律、公式，**在语境中留空呈现**（不孤立罗列）」。
4. **errorbook｜【创作要求】3 指向的条款不在所指数块（跨处指代错位）**
   - 描述：指「见【输出格式】的块内组织条款」，但【输出格式】并无该条款，实际在【编号与组织】与【易错题本结构】。
   - 应在何处：【创作要求】3 的指向应改为【编号与组织】/【易错题本结构】。
   - 证据：逐字——「3. **逐题成组**的分项次序与块内层级，见**【输出格式】**的块内组织条款」↔（实际出处）「每道题在所属块内**依次成组**：同一道题的各分项紧接在该题之下依次给出（题目呈现→典型错解→错因剖析→正确解答→方法提炼→变式训练）」。
5. **全片｜【物理·高中要点】含「光路作图」，对高一存在跨学段指向**
   - 描述：该要点按「高中」笼统给出，未按本学段收窄；高一（必修）未涉及光路作图。
   - 应在何处：【物理·高中要点】应按学段分档，或声明「以本单元实际范围为准」。
   - 证据：逐字——「【物理·高中要点】受力分析、电路与光路作图规范；实验探究重原理与数据处理；运用物理规律解决问题过程完整、步骤严谨。」

## 五、附录·改进空间（不计入判定）

1. exam：各大题**只给分值未给题量**；建议补题量或写明「题量由内容决定，以账目为准」。
2. exam：卷首「密封线（…含学校/班级/姓名/学号填写栏）」的**渲染载体**未指定（行内 vs 表格）；建议明确。
3. practice/special/reading：组织风格 `scenario_each` 与【质量底线】「考查基础概念、规则与技能时，情境从简或不用」并存；建议在组织风格档位说明中写明「基础概念题可从简/不用情境」的例外。
4. practice/special：栏「基础巩固」要求「按本单元内容自然成栏」/「每栏含…」等**未量化**；建议给量级参考。
5. preview：创作要求「先读教材、再梳理要点、后带着疑问进课堂」的**顺序**与栏序（学习目标／旧知回顾／…）无一一对应；建议增设「梳理要点」或说明其归并。
6. summary：「标记」先行词不明，建议改为「强调标记（加粗）」；「载体只用于作答位」与「导图块」关系建议明确界定。
7. review：「知识网络化呈现」与 `framework`「各项以要点成行成列列出」措辞不一，建议统一。
8. errorbook：分项用 `<h4>` 而**未定义 `<h3>`**（h2→h4 跳层），建议说明分项层级样式或调整层级。
9. dictation：栏「书写呈现——公式与单位书写规范呈现」未说明是**示范**还是**留空默写**；建议明确作答形态。
10. 全片各教辅类：「相应充实的训练量」「全面细致」「精炼」「高频」等**无量化**，建议给可用量级。
