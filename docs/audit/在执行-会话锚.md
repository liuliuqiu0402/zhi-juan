## 五、执行者纪律（从 2026-10-11 起生效）

1. **三段式**：开工先贴【本轮声明】（本事务／成员条／边界／验收物／本轮预算够不够做完）；收工贴【本轮交底】（改动清单／**验收命令＋原始输出**／commit hash）。**无命令输出不得称"完成"。**
2. **不够就不做**：单轮预算不足完成一个事务组时，**明说"本轮不做"**，不做到一半。
3. **批次＝事务**：同一事务的多条**必须一次改完**；跨事务耦合须在聚类表标注，按拓扑序做。
4. **探针前置**：每事务的 L1 计数锚 ＋ L2 互斥探针**与修复同时写**，不事后补。
5. **先声明后动手**：不得先改再解释。
6. **换人签核**：每完成一大批，**换新会话**只拿"注入后的完整 prompt 文本"重审（L4）——承认自检有盲区。
