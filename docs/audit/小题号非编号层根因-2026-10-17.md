# 留痕：小题号"硬编号"的非编号层根因 ＋ 分值单源清理（2026-10-17 第三轮）

> 属主口径："**编号层面如果没有错，就从其他可能导致硬编号的情况切入找根因**"。
> 本轮找到并修掉的是**答案区**那一条——它与编号判据无关，却在反向要求"正文每个题都得有号"。

---

## 一、根因：答案区"严禁省略题号层"与同句"未编号的不编号"自相相抵

四处同型文本，句式都是"**先给条件、再给绝对句**"：

| 位置 | 原句 |
|---|---|
| `useAiGenerator:4667`（答案页·普通分支） | `答案区**每个题目都以与正文完全相同的题号起头**…（**正文未编号的题，答案同样不编号**）…**严禁省略题号层**` |
| `useAiGenerator:4666`（答案页·自包含分支） | `正文题目带题号时，答案区逐题以相同题号起头…**严禁省略题号层**` |
| `promptLibrary:1811`（once·自包含） | `每题以与正文相同的题号起头（正文未编号的题，答案同样不编号），**严禁省略题号层**` |
| `promptLibrary:1818`（once·正式卷） | 同型 |

**为什么这会逼出正文硬编号**：模型要同时满足两句，只能取**更强**的那句（"严禁省略题号层"）。
而正文里"整栏同类项"（口算/算式/看拼音整栏）本来就没有题号层 ⇒ 唯一的解法就是**给它们补上题号**，
好让答案能"逐题同号"。这就是编号判据没错、却仍出现硬编号的一条外因。

台账里早有先例记录（`三维度逐条重造-台账.md` 5746：`答案必带号 → 正文必须有号`，处置＝加前件），但只补了括注、**绝对句没改**，所以一直没消。

### 处置：四处统一改**条件式**（判据不放松）

| 改后 |
|---|
| `正文**给了题号**的题，答案以**同一题号**起头` |
| `正文**未编号**的题（整栏同类项、整栏算式等），答案按**该（大题/栏目）内的作答顺序**逐项给出、**不另造题号**` |
| `**正文有题号层的，不得省略该层、也不得用「(1)(2)」括号序号或纯列表代替**`（原绝对句降为条件句，反代号的禁止保留） |

同步契约：`blockStructure`（ANS_INLINE 逐字镜像）、`bodyContinuationWiring`、`recipe/promptLibrary`（once 两例）、
`caliberRegistry`（ansAlignNote 的 head 改指新句）——全部按产出改准，未放宽。
