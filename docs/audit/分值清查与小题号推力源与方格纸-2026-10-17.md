# 留痕：分值全局清查 ＋ 小题号两条推力源 ＋ 方格纸兜底（2026-10-17）

## 一、分值：全局清查结果（实发 exam|数学|primary_mid 逐行核过）

**结论：旧的作废干净了。** 现在与分值有关的只有四类，各有明确职责：

| 位置 | 内容 | 性质 |
|---|---|---|
| 卷面结构说明 | 「所标分值只是份量参考，不是标题里要填的数字」 | **结构参考层**（另一件事：结构可增可减） |
| 【编号与分值】第 1 条 | 大字标题形如「一、〈名称〉（分值说明）」 | **形状占位**（写法不在此处规定） |
| 计分对象口径（2 条） | 什么算"一处"、单价单位怎么取、与编号不是同一把尺、对错档出口 | **定义**（新规则的计算基础） |
| 分值标注 + 账目 | 标题「（共X分）」／每独立题干后「每X分，共Y分」／标题即题干则标题承载；四层账目 | **现行 A 侧** |

**实测计数（全卷模板）**：`等分` 0 处、`全卷连续` 0 处、`应编号的题` 0 处、`分值说明＝` 0 处。
已作废的旧表述（标题只写总分、逐题只标「（X分）」、等分/不等分两口径、整大题一次乘法、自证逐题累加）**均已不在实发中**。

## 二、小题号：找到两条与编号无关的"推力源"（属主真机证据）

真机产物：

```
一、直接写得数（每题1分，共14分）
1. 直接写出下面各题的得数。
二、列竖式计算（每题3分，共12分）
2. 用竖式计算下面各题，书写要规范。
```

每个大题只有**一个**题干，却各带一个小题号，且题号跨大题连续（1、2）——正是"整大题只含一个编号对象时，其下不再另起题号与题干行"被违反的样子。两处外力：

| 推力源 | 原文 | 为什么是它 |
|---|---|---|
| 大题序号「**全卷连续**」 | `大题序号：**全卷连续（一、二、三…）**` | "连续"二字没有限定层级，模型会推广到题号层 ⇒ "题号要连续 ⇒ 每个题干都得有号"。已改为 **「一、二、三…（跨大类/部分接着编，不重新起头）」**（顺序规则不变，去掉"连续"这个动词化暗示） |
| 渲染契约「**应编号的题**…并**带题号**」 | `**应编号的题**以 <p class="question"> 包裹并带题号` | 它在渲染段又判了一次"哪些该编号"，与"编号只定层级"撞车；且"带题号"是硬要求。已改为 **「每个独立题干用 <p class="question"> 包裹（**给不给题号都这样包裹**）」**——包裹是结构，编号由层级口径决定 |

**两处都加了反向锁**：`全卷连续`、`应编号的题` 若回潮即判红。

## 三、方格纸：程序侧原来只补"空白作图区"，从不补方格

- 现状：题干点名"在方格纸上画"的题，程序命中的是 `specNeeds='作图'`，兜底一律插 `<div class="draw-area">`（**虚线空白框**）——所以"有框没格"。
- `square-grid` 一直存在（CSS/编辑器/Word 三端都支持），但**只由编辑器手动插入**，生成链从不自动补。

**已补确定性兜底**（`examValidator` 2k 专用作答区）

| 条件 | 兜底 |
|---|---|
| 题干含 `方格纸/方格图/方格中/格子图/格子纸` + **小学段** + 该题无任何作答载体 | 插 `<div class="square-grid">`（方格纸） |
| 同上但**中学段** | 仍走 `draw-area`（排版规格：square-grid 仅小学段合法；初中以上由答题纸自带网格） |
| 题目已有 `draw-area`/`square-grid` | 不动 |

测试：`answerAreaContextGuard` 新增两例（小学补方格纸、中学不补方格纸仍补作图区）。

## 四、验证

- 定向：`answerAreaContextGuard` 12 例全绿；`qualityReadiness`／`questionObjectCaliber`／`blockStructure` 绿。
- 全量：见提交信息；构建通过。
- **须真机复核**：①整大题只有一个题干时，其下**不再**出现「1.」；②"在方格纸上画"的题**有方格**；③分值仍是"标题共X分 + 每题干单价"，多档标题由程序转成分组式。
