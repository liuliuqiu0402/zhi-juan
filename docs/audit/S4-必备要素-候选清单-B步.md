## 逐类的【创作要求】（原文，作为"必备要素"的第一手候选）

### 正式考卷（`exam`）
- 1. 依据2022年版义务教育课程标准命题：素养立意
- 2. 以{unit}为命题范围：选文、情境可来自课外
- 3. 每道题可直接作答（材料与作答位齐备）；所有题目原创设计
- 4. 需材料/选文的题目先给出完整材料再设问
- 5. 设选项时，各选项须各自对应一种学生可能的思路
- 6. 设问由易到难，考查理解与运用
- 7. 练到本学段课标学业要求
- 8. **每个大题只出一个标题**（标题写法见【大题标题命名】）；**大题标题之外的题默认不另配标题**；**仅当同一大题下各题的作答方式不同类时**，才须给出足以让答题者知道"怎么答"的小组标题或说明；**标题名须与其下实际内容自洽**（层级样式见"序号体系"）

### 同步练习（`practice`）
- 1. 按课标倡导的学习方式组织（在真实情境中开展学习活动、形成可见成果）
- 2. 内容与本次教材范围对应
- 3. 在本次勾选范围的基础上安排相应充实的训练量
- 4. 每道题完整可作答

### 专项突破（`special`）
- 1. 按核心知识归类，便于集中突破
- 2. 在本次勾选范围的基础上安排相应充实的训练量
- 3. 聚焦{unit}薄弱点
- 4. 题目完整可作答

### 预习导学（`preview`）
- 1. 设计少量可操作、可检查的预读内容，形式灵活、不预设具体形式，须含"我的疑问"
- 2. 紧扣教材原文
- 3. 预习按先读教材、再梳理要点、后带着疑问进课堂的顺序推进

### 阅读训练（`reading`）
- 1. 在本次勾选范围的基础上安排相应充实的训练量

### 知识总结（`summary`）
- 1. 在本次勾选范围的基础上全面细致地汇总知识
- 2. 表述精炼；核心知识**标注重点**（标注形式见【输出格式】的强调口径）
- 3. 「典型例题」栏目为讲解示范定位：例题就是一道**完整的题**——**该用什么形态就用什么形态**
- 4. 载体只用于作答位；整句/整段以正文呈现，答案与解析不整块包进标记

### 默写积累（`dictation`）
- 1. 严格对应教材要求

### 易错题本（`errorbook`）
- 1. 按知识点或错因分块组织，每块下逐题
- 2. 题目取自本单元高频易错点，每题须对应一个典型错因
- 3. **逐题成组**的分项次序与块内层级，见【输出格式】的块内组织条款

### 复习资料（`review`）
- 1. 在本次勾选范围的基础上汇总核心知识
