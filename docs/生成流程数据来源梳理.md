# 生成流程数据来源梳理

> 覆盖范围：整卷一次生成链路（指令库驱动，无分步流水线）
> 更新日期：2026-08-24

## 数据流全景

```
用户输入 → 指令组装 → 素材检索 → AI 生成 → 后处理 → 渲染/存储
   │          │          │          │         │         │
 ① UI配置   ② 指令库    ③ 教材数据  ④ 附加块   ⑤ 代码兜底  ⑥ 导出/记录
```

## ① 用户输入层（GenerateModule UI）

| 数据 | 来源 | 去向 |
|---|---|---|
| selectedBooks（学科/学段/年级/目录/勾选章节） | 教材库勾选 | 决定学段学科、范围名、素材检索范围、指令库匹配 |
| genType（9 类资料类型） | 类型选择 | 指令库匹配、蓝图结构 |
| scopeType + scopeOverride | 范围类型 + 弹窗确认名 | 范围名（unit）→ 指令/标题 |
| propositionStyle（命题风格） | 风格配置 | 情境框架 contextFramework 附加块 |
| examRegion（省市） | 地区选择 | 蓝图覆盖（总分/时长/板块分值） |
| selectedTemplates（模板勾选） | 模板库 | 模板对标 templateInfo 附加块 |
| instructionDraft + 用户附加 | 指令框（可编辑） | prompt 主体 |
| batchCount / mode | 生成设置 | 份数、单份/批量/逐章 |

## ② 教材内容数据层（分析阶段产出）

| 数据 | 来源 | 去向 |
|---|---|---|
| contentCards[].segments[].{text,type,knowledgePoints} | 教材 OCR + AI 分析 | 素材检索、知识点标注 |
| knowledgeMap（知识点 + 知识图谱：单元→大概念→核心知识，带认知层级） | 分析阶段 | 知识点清单注入指令 |
| semanticRetriever（语义检索索引） | 分析后构建 | 按知识点检索原文片段（RAG） |
| outline（目录树） | 教材库 | 范围推断、章节目录 |

## ③ 指令层（promptLibrary.js）——注入指令的唯一来源

| 数据 | 来源 |
|---|---|
| 内置模板 540 个（486 三维度 + 45 学段×类型 + 9 通用） | TYPE_BASES（9 类型骨架）× 学科要点 × 学段特点 × 学段学科矩阵 生成 |
| 用户自定义模板 | localStorage（wisdom_prompt_library_v1），面板可维护 |
| 占位符 {grade}{subject}{unit}{scope}{structure}{fullScore}{duration}{material}{extra} | 系统数据注入 |
| 渲染契约 [GRAPH]/公式/[IMAGE] | eduRenderContract.js 按 学科×类型×配图 注入 |
| 匹配链 | 用户三维度 → 用户学科×类型 → 用户类型 → 内置三维度 → 内置学段×类型 → 内置通用 |

## ④ 生成执行层（generateFullPaperNatural）

```
prompt = 注入指令（指令库渲染）
       + 【教材原文】（按知识点检索：目录+知识点清单+相关片段，≤8000字）
       + 【模板对标】（用户勾选模板，可选）
       + 【情境框架】（命题风格，可选）
       + 【差异化要求】（复生成，可选）
→ callAI（DeepSeek，正文 8192 tokens；答案页独立调用）
→ 后处理：清洗 → 空白规范化 → 截断续写 → 答案页独立生成 → 密封线兜底
```

## ⑤ 静态规范库

| 数据 | 来源 | 用途 |
|---|---|---|
| 卷面结构/满分/时长 | examPaperBlueprints.js + blueprintProvider.js | {structure}{fullScore}{duration} 占位符 |
| 地区差异覆盖 | examRegionConfig.js | 蓝图按地区调整 |
| 范围推断/弹窗候选 | paperScope.js（inferPaperScope/buildScopeCandidates） | 范围名 + 确认弹窗 |
| 学科/学段体系 | expertKnowledge.js | 下拉选项、匹配键 |

## ⑥ 渲染与存储层

| 数据 | 来源 | 去向 |
|---|---|---|
| docxBuilder | 导出 | [IMAGE] 占位、docx 生成 |
| copyToEduRender | 渲染 | 公式/[GRAPH]/[IMAGE] 标记 → EduRender Studio |
| generatedDocs | 会话 | 结果列表（标题取 AI 的 h1） |
| docHistory | 本地存储 | 历史记录（50 条上限） |

## 关键设计原则

1. 内容质量由"教材分析数据（②）+ 指令库（③）+ 用户配置（①）"共同决定
2. 生成前素材按知识点检索注入（RAG，非全量/非硬截断）
3. 生成后由代码兜底排版（空白规范化/密封线/答案页锚定）
4. 指令库/蓝图内容遵循：三维度针对性 + 新课标符合 + 不抑制 DeepSeek 命题能力

## 1. 格式要求全覆盖（非 exam 类型）

- **exam**：整卷生成指令尾部注入 `buildBlueprintInjection(bp)`——真题蓝本题型骨架（板块+分值+板块命题要求 note）+ 学段/学科新课标条款（质量底线）；头部固定"【卷面结构（真题蓝本，板块与分值固定，不得增删改）】"。卷面规范全文（密封线/横线/方格纸）不进注入指令（模板【卷面格式】人话版承担），避免指令冗余。

## 5. 生成执行层 8192 tokens 上限评估

| 环节 | 预算 | 评估 |
|---|---|---|
| 整卷正文一次生成 | `maxTokens: 8192`（≈2.4 万中文字符；options.maxTokens 优先，显式生效） | 小学/初中卷正文 4000-15000 字够用；高中 150 分卷（大阅读语篇+作文）可能截断 |
| 截断续写兜底 | 检测尾部无闭合标签/结束标点 → 追加"【续写】"再 8192 → 有效上限 16384 tokens（≈5 万字符） | 覆盖全部学段整卷，无需调整 |
| 答案页独立调用 | 8192 + retries:1；输入为提取的题目清单（h2 板块 + question/option 纯文本，≤15000 字） | 够用 |
| 输入侧 | 注入指令（模板自带格式 + 蓝图骨架与新课标条款约 1 千字）+ 素材 RAG ≤8000 字 + 可选附加块 | 远小于 DeepSeek 64K 上下文 |

- 结论：8192 够用；实际兜底预算 16384 tokens。不因极端情况增加复杂度（续写检测启发式保持现状，符合"不过度"原则）。

## 9. 质量底线三维度注入（类型/学科/学段各司其职，非一刀切）

- **背景**：审核反馈三类问题（题集类缺分类分层/重复、内容单薄、图不符/空洞/超纲/逻辑乱/无关）的根因是质量底线只约束 exam（蓝图条款仅 exam 注入），非 exam 模板几乎无约束。
- **落地（三维度针对性，不用通用块"一股脑"塞全部模板）**：
  - 类型维度 → 各类型模板【要求】：practice 防机械重复/任务完整、special 分类分层+变式换情境、preview 覆盖全部新知识点、reading 短文完整不截断+同一考点不重复、summary 不遗漏、dictation 覆盖全部字词篇目不遗漏、errorbook 归因+变式换角度、review 自测按考点分布
  - 学科维度 → SUBJECT_EXAM_EXTRAS 15 学科末尾"底线"条：语文防原句挖空/语境考查、数学情境建模/说理/防孤立概念、英语语篇完整地道/无中式英语、理化生实验完整/防孤立概念、史地材料论从史出/图表载体、思政道法时政/知行合一、科学探究完整、信息科技数字化情境、音体美素养导向
  - 学段维度 → STAGE_EXAM_EXTRAS 5 学段末尾"认知底线"条（不超学段认知水平）：低段只考本册已学、中段不超前引入高段知识、高段不超高段课标、初中对标中考不超纲、高中符合课标学业质量
- **超纲的正确含义**（用户确认）：不超**学段认知水平**，而非"不超出教材"——课标本身鼓励课外拓展（语文课外阅读、英语真实语篇、数学跨学科实践、道法时政），措辞中无"禁止教材外概念"类限死约束。
- **图一致性**：渲染契约 [IMAGE] 增加"PROMPT 画面要素须与题干情境严格一致（人物/场景/数量）"，防"图片与内容不符"。
- 三维度模板（486）打开即见对应维度的针对性底线（类型底线 + 学科底线 + 学段认知底线组合）。
- 测试：333 条全绿（质量底线三维度断言 4 条：类型/学科/学段/课外拓展）。
