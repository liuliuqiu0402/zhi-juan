# 🚀 智卷工坊 · 快速启动指南

## ⚡ 3分钟快速开始

### 第1步：检查环境（30秒）

打开命令行，运行：
```bash
node --version    # 应显示 v18.x 或更高
python --version  # 应显示 Python 3.9 或更高
```

如果未安装，请先下载：
- Node.js: https://nodejs.org/
- Python: https://www.python.org/downloads/

---

### 第2步：安装依赖（1分钟）

#### 方式一：一键安装（推荐）
```bash
# 双击运行
install.bat
```

#### 方式二：手动安装
```bash
# 1. 安装 Node.js 依赖
npm install

# 2. 安装 Python 依赖
pip install -r requirements.txt
```

---

### 第3步：启动应用（30秒）

```bash
# 双击运行
start.bat

# 或命令行执行
npm start
```

应用将在几秒内启动！🎉

---

## 📝 首次使用配置

### 1. 激活应用
启动后会看到激活界面，输入激活码完成验证。

### 2. 配置 AI（可选但推荐）

#### 方案 A：本地 Ollama（免费，离线可用）
```bash
# 1. 下载安装 Ollama
# https://ollama.com/download

# 2. 拉取模型（约需 5-10 分钟）
ollama pull qwen2.5:7b      # 文本生成
ollama pull qwen3-vl:8b     # 图片识别

# 3. 启动服务
ollama serve

# 4. 在应用中刷新模型列表
# 进入「系统设置」→ 点击「刷新模型列表」
```

#### 方案 B：云端 DeepSeek（需要 API Key）
1. 注册账号: https://platform.deepseek.com
2. 获取 API Key
3. 在应用中配置：
   - 进入「系统设置」
   - 选择 "DeepSeek" 引擎
   - 填入 API Key
   - 保存

## 🆘 常见问题速查

### Q: 启动时报错 "Cannot find module 'pinia'"
```bash
npm install pinia
```

### Q: PDF 转图片失败
```bash
pip install PyMuPDF Pillow
```

### Q: Ollama 服务未运行
```bash
# 启动 Ollama
ollama serve

# 检查状态
curl http://localhost:11434/api/tags
```

### Q: 想查看控制台日志
按 `F12` 打开开发者工具
